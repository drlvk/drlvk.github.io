TestThe second derivative test

One new idea in section 11.5 is the second derivative test: the sign of \(f''\) can help us distinguish between a local maximum and a local minimum. So far, we only used \(f'\) for that.

Worth memorizing

  • If \(f'(x) = 0\) and \(f''(x) < 0\) at some point, then it is a local maximum.
  • If \(f'(x) = 0\) and \(f''(x) > 0\) at some point, then it is a local minimum.

If you don’t remember which sign means what, just sketch a concave curve.

How to use the second derivative test

  1. Find \(f'(x)\).
  2. Solve \(f'(x) = 0\) to find the critical numbers of \(f\).
  3. Find \(f''(x)\).
  4. Plug each critical number from step 2 into \(f''(x)\), and make a conclusion based on the sign of the result.

This test does not involve making a sign chart.

Example 1. Use the second derivative test to find the local maxima and minima of the function \(f(x) = x^3 - 75x\).

Show solution
  1. 1. f′\(f'(x) = 3x^2 - 75\)
  2. 2. Solve\(3x^2 - 75 = 0\); divide by 3: \(x^2 - 25 = 0\), \(x^2 = 25\), so \(x = 5\) or \(x = -5\). These are the critical numbers to test.
  3. 3. f″\(f''(x) = (3x^2 - 75)' = 3 \cdot 2x - 0 = 6x\)
  4. 4. Plug 5\(f''(5) = 6 \cdot 5 = 30 > 0\): concave up, a local minimum
  5. 4. Plug −5\(f''(-5) = 6(-5) = -30 < 0\): concave down, a local maximum

Answerlocal max at x = −5; local min at x = 5

The values are \(f(-5) = -125 + 375 = 250\) and \(f(5) = -250\).

Do not set f″ = 0

In this test, \(f''\) is never set equal to 0: that is not what the second derivative test is. Solve \(f' = 0\) for the critical numbers, then only evaluate \(f''\) at them. (Setting \(f'' = 0\) is for inflection points.)

Note that the second derivative test tells us nothing when \(f''(x)\) is 0 or undefined at a critical point. At such points the function may have a local maximum, minimum, or no extremum at all: we cannot determine this from this test. Fortunately, this inconclusive case rarely occurs in practice. When it does, go back to the sign chart for \(f'\).

Example 2. Use the second derivative test to find the local maxima and minima of the function \(f(x) = \dfrac{2x^2 + 72}{x}\).

Show solution

Find \(f'\), solve \(f' = 0\), find \(f''\), and plug the critical numbers into \(f''\).

  1. Rewrite\(f(x) = 2x + \dfrac{72}{x} = 2x + 72x^{-1}\)
  2. f′\(f'(x) = 2 + 72(-1)x^{-2} = 2 - \dfrac{72}{x^2}\)
  3. Solve\(2 - \dfrac{72}{x^2} = 0\): \(2 = \dfrac{72}{x^2}\), \(2x^2 = 72\), \(x^2 = 36\), so \(x = 6\) or \(x = -6\), the critical numbers to plug into \(f''\)
  4. f″\(f''(x) = \left(2 - 72x^{-2}\right)' = -72(-2)x^{-3} = \dfrac{144}{x^3}\)
  5. Plug in\(f''(6) = \dfrac{144}{6^3} > 0\) (min);   \(f''(-6) = \dfrac{144}{-6^3} < 0\) (max)

Answerlocal max at x = −6; local min at x = 6

The values are \(f(-6) = -24\) and \(f(6) = 24\): once again a local maximum below a local minimum, on opposite sides of the asymptote at \(x = 0\).

DefinitionAbsolute extrema on a closed interval

Earlier we studied the process of finding local maxima (where \(f\) is greater than at nearby points) and local minima (where \(f\) is smaller than at nearby points). But it may be of more interest to find the greatest (or smallest) values of a function overall: on the entire domain of the function, or on some interval.

A natural reason to focus on some interval is that the range of reasonable actions is limited. For example, if one considers the monthly price \(p\) of a digital subscription, it is unlikely to be less than $5 or more than $20, so one considers the interval \([5, 20]\) and looks for the maximum of some function (revenue? profit?) on that interval.

Definition

Given a function \(f\) and some interval \([A, B]\):

  • \(f\) has an absolute maximum at \(a\) if \(f(a) \ge f(x)\) for all \(x\) in the interval;
  • \(f\) has an absolute minimum at \(a\) if \(f(a) \le f(x)\) for all \(x\) in the interval.

An absolute extremum is either an absolute maximum or an absolute minimum.

Usually we are given a formula for \(f\), not its graph. To find the absolute max and min, we follow the steps below.

How to find absolute extrema on an interval [A, B]

  1. Find the derivative \(f'\).
  2. Solve \(f' = 0\) to find the critical numbers of \(f\) that lie between \(A\) and \(B\).
  3. Plug the endpoints \(A\), \(B\) and the critical numbers into \(f\). (Not into its derivative! We are not making a sign chart here.)
  4. Pick the greatest and smallest of the values found in step 3.

Unlike in the search for local extrema, we do not need a sign chart for \(f'\). The endpoints and critical numbers form a “list of candidates,” and the answer is among them.

Example 1Absolute max and min of a quotient

Find the absolute maximum and minimum of the function \(f(x) = \dfrac{x}{x^2 + 1}\) on the interval \([0, 2]\).

Show solution

The endpoints 0 and 2 are among the candidates.

  1. 1. f′\[f'(x) = \frac{(x)'(x^2+1) - (x)(x^2+1)'}{(x^2+1)^2} = \frac{x^2 + 1 - 2x^2}{(x^2+1)^2} = \frac{1 - x^2}{(x^2+1)^2}\]
  2. 2. Solve\(f' = 0\) when \(1 - x^2 = 0\), so the critical numbers are 1 and \(-1\). But \(-1\) is not in \([0, 2]\): disregard it.
  3. 3. Plug inthree candidates, 0, 2, and 1; plug each into \(f\), not \(f'\): \(f(0) = \frac{0}{0+1} = 0\),   \(f(1) = \frac{1}{1+1} = \frac12 = 0.5\),   \(f(2) = \frac{2}{4+1} = 0.4\)
  4. 4. Pickthe greatest and smallest of the \(y\) values found

Answerabsolute max 0.5 at x = 1; absolute min 0 at x = 0

Four different tools for different tasks:

Which tool to use
To find…We use…
Increasing/decreasing intervals, local maxima and minimaSign chart for the first derivative

Local maxima and minimaSecond derivative test. No sign chart needed.

There are relations between these.

  • The second derivative test gives the same kind of information that we get from the sign chart for \(f'\), which is known as the first derivative test.
  • When a function has just one local extremum, that extremum is also absolute: one local max is the absolute max, one local min is the absolute min. This fact often simplifies the search for an absolute extremum.

Example 2Absolute max and min of a cubic

Find the absolute maximum and absolute minimum values of the function \(f(x) = x^3 - 3x^2 - 9x\) on the interval \([0, 4]\).

Show solution
  1. 1. f′\(f'(x) = 3x^2 - 6x - 9 = 3(x^2 - 2x - 3) = 3(x - 3)(x + 1)\)
  2. 2. Solve\(3(x - 3)(x + 1) = 0\) when \(x = 3\) or \(x = -1\). But \(-1\) is not in \([0, 4]\): disregard it.
  3. 3. Plug incandidates 0, 4, and 3:   \(f(0) = 0\),   \(f(4) = 64 - 48 - 36 = -20\),   \(f(3) = 27 - 27 - 27 = -27\)
  4. 4. Pickthe greatest is 0, the smallest is \(-27\)

Answerabsolute max 0 at x = 0; absolute min −27 at x = 3

Endpoints can win

Here the absolute maximum is at an endpoint, \(x = 0\), where \(f'\) is not 0. That is why the endpoints are always on the list of candidates.
