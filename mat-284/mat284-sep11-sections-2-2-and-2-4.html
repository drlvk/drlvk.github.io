Warm-upA quadratic, and a trap

Solve \(3x^2 = 7x + 5\).

Show solution
  1. Standard form\[3x^2 - 7x - 5 = 0\]
  2. Read off\(a = 3\), \(b = -7\), \(c = -5\)
  3. Formula\[x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\]
  4. Discriminant\((-7)^2 = 49\), so \[49 - 4\cdot 3\cdot(-5) = 49 + 60 = 109\]
  5. Substitute\[x = \frac{7 \pm \sqrt{109}}{6}\]

Answerx = (7 ± √109)/6 ≈ 2.907 or −0.573

What not to do

Do not take a square root of both sides. Writing \(\sqrt{3x^2} = \sqrt{7x+5}\) gains nothing, and simplifying it to \(\sqrt{3}\,x = \sqrt{7x} + \sqrt{5}\) is simply false: a square root does not distribute over a sum.

The square-root method needs an equation with an \(x^2\) term and no first-power term. This one has both, so the quadratic formula is the tool.

And watch that sign

\((-7)^2 = 49\), not \(-49\). Writing \(-7^2\) means \(-(7^2)\), which is where the sign gets lost. With \(b = -7\) the term \(-b\) becomes \(+7\), so the numerator opens with \(7\), not \(-7\).

DefinitionConstant and linear functions

Recall that a function takes a single number and outputs a single number. “Take the square root and double it” can be written \(f(x) = 2\sqrt{x}\) or as \(y = 2\sqrt{x}\). Both notations have their merits: the first names the function \(f\), the second names the output \(y\).

Constant functions

A constant function outputs the same number no matter what the input is. For example \(f(x) = 10\).

For \(f(x) = 10\), what is \(f(3)\)?

Show solution

Answerf(3) = 10

Because this function always outputs 10. There is no \(x\) in the formula to substitute into, which is exactly what makes it constant.

Linear functions

Linear functions have the form \(f(x) = ax + b\), where \(a\) and \(b\) are numbers. They model steady growth or decline, and we have already met them as total cost and profit in terms of the quantity \(x\).

The total cost is \(f(x) = 7500 + 20x\). Find the variable cost per unit and the fixed cost.

Show solution
  1. Variablethe coefficient of \(x\): \(20\) per unit
  2. Fixedthe constant term: \(7500\)
  3. Same thing\[f(0) = 7500 + 20\cdot 0 = 7500 + 0 = 7500\]

Answer$20 per unit variable, $7,500 fixed

The fixed cost is the cost of producing nothing, which is why it equals \(f(0)\). That reading works for any linear model, so you never have to remember which number is which.

DefinitionAbsolute value and piecewise functions

The absolute value function has its own notation, \(|x|\), and it is defined by two formulas rather than one.

\[|x| = \begin{cases} x, & \text{if } x \ge 0 \\ -x, & \text{if } x < 0\end{cases}\]

So \(|-7.4| = 7.4\) and \(|2.3| = 2.3\). The conditions to the right of the formulas are what tell you which formula applies.

More generally, a piecewise-defined function uses a different formula on different parts of its domain, possibly with more than two cases.

\[f(x) = \begin{cases} 5x, & \text{if } x \le 10 \\ 50, & \text{if } x > 10\end{cases}\]

For the function above, find \(f(3)\) and \(f(13)\).

Show solution
  1. f(3)\(3 \le 10\), so use the first formula: \(5 \cdot 3 = 15\)
  2. f(13)\(13 > 10\), so use the second formula: \(50\)

Answerf(3) = 15 and f(13) = 50

Check the condition before substituting. The formula you would have used is irrelevant once the input lands in the other case.

Where these come from

Piecewise functions describe contracts and agreements with conditions attached, such as a cap on a total.

A company will donate $5 to charity for each sale, up to a total of $10,000. Write the donation as a function of \(x\), the quantity sold.

Show solution

Two regimes: below the cap the donation grows with sales, and above it the donation is frozen at the cap. The work is finding where the boundary sits.

  1. Below cap\($5\) per unit gives \(5x\)
  2. Boundarythe cap is reached when \[5x = 10000 \quad\Longrightarrow\quad x = 2000\]
  3. Above capthe donation stays at \(10000\)

Answerf(x) = 5x if x ≤ 2000, and f(x) = 10,000 if x > 2000

The $10,000 in the problem is a limit on the donation, not on the quantity. Converting it into a limit on \(x\) is what the middle step does, and it is the only real work in the problem.

Worked exampleA piecewise word problem

A salesperson is paid $20 for each gadget sold, up to 100 gadgets, and $25 for each sale beyond 100. Find the total income as a function of \(x\), the number of gadgets sold.

Show solution

Split the \(x\) gadgets into the first 100 and the rest.

  1. Up to 100every gadget pays $20, so the income is \(20x\)
  2. Beyond 100the first 100 pay \(20 \cdot 100 = 2000\), and the remaining \(x - 100\) pay $25 each
  3. Second case\[20\cdot 100 + 25(x - 100)\]
  4. Simplify\[2000 + 25x - 2500 = 25x - 500\]

Answerf(x) = 20x if x ≤ 100, and f(x) = 25x − 500 if x > 100

The $25 applies only to the excess

Writing \(25x\) for the second case pays the higher rate on all \(x\) gadgets, including the first 100. The quantity earning $25 is \(x - 100\), the same structure as the commission problem from Aug 28.

DefinitionPolynomials

A quadratic polynomial has the form \(f(x) = ax^2 + bx + c\), where \(a\), \(b\), \(c\) are coefficients. It is also called a polynomial of degree 2, because 2 is the highest power of the variable. The coefficient of that highest power is the leading coefficient.

Polynomials of other degrees work the same way. In general a polynomial is various powers of \(x\) with coefficients, all added together.

Two things to read off

  • Degree: the highest power the variable is raised to.
  • Leading coefficient: the number multiplying that highest power, sign included.

Find the degree and leading coefficient of

a) \(f(x) = 7x + 8 - \dfrac{x^2}{3}\)    b) \(7x^3 - 4x^5 + 18\)

Show solution

Neither is written with the powers in order, so reorder them first.

  1. a) Reorder\[-\frac{1}{3}x^2 + 7x + 8\]
  2. a) Read offdegree \(2\), leading coefficient \(-\frac{1}{3}\)
  3. b) Reorder\[-4x^5 + 7x^3 + 18\]
  4. b) Read offdegree \(5\), leading coefficient \(-4\)

Answerdegree 2 with −1/3;   degree 5 with −4

In both cases the highest power carries a minus sign, and the minus sign is part of the leading coefficient. It is not \(\frac{1}{3}\) or \(4\).

The exponents have to be non-negative integers

\(\sqrt{x} = x^{1/2}\) is not a polynomial, and neither is \(x^{3.5}\). A fractional power disqualifies the expression no matter how ordinary the rest of it looks. The same goes for a variable in a denominator, which is a negative power.

DefinitionRational functions

Sometimes a polynomial is not written in expanded form, and finding the degree means expanding it first.

Expand \(f(x) = (1 - 2x^2)(2x - 3x^5)\), then give its degree and leading coefficient.

Show solution

Multiply each term of the first factor by each term of the second.

  1. Four products\[1\cdot 2x + 1\cdot(-3x^5) + (-2x^2)(2x) + (-2x^2)(-3x^5)\]
  2. Simplify\[2x - 3x^5 - 4x^3 + 6x^7\]
  3. Reorder\[6x^7 - 3x^5 - 4x^3 + 2x\]
  4. Read offdegree \(7\), leading coefficient \(6\)

Answer6x⁷ − 3x⁵ − 4x³ + 2x, degree 7, leading coefficient 6

Adding exponents is what produces the 7: \(x^2 \cdot x^5 = x^7\), since \(xx \cdot xxxxx\) is seven copies of \(x\). Likewise \(x^2 \cdot x = x^3\).

So multiplying two polynomials gives another polynomial. Dividing one by another gives something new, a rational function:

\[f(x) = \frac{\text{one polynomial}}{\text{another polynomial}}\]

For example,

\[f(x) = \frac{5x^3 + 1}{x^2 + 4x}\]

Polynomials are defined for every value of \(x\). Rational functions may not be: they can have vertical asymptotes where the denominator turns to 0 and the function is undefined. These are precisely the numbers excluded from the domain.

Find the vertical asymptotes and the domain of \(f(x) = \dfrac{5x^3 + 1}{x^2 + 4x}\).

Show solution
  1. Denominator\[x^2 + 4x = 0\]
  2. Factor\[x(x + 4) = 0\]
  3. Spliteither \(x = 0\) or \(x + 4 = 0\)
  4. Solve\[x = 0 \quad\text{or}\quad x = -4\]

Answerasymptotes at x = 0 and x = −4; domain is all x except 0 and −4

Factor the denominator, don't use the quadratic formula

\(x^2 + 4x\) has no constant term, so \(x\) is a common factor and the roots come out in one line. Reaching for the quadratic formula here works but takes four times as long, and this denominator shape is extremely common.

Worked exampleDomain of a rational function

Recall: how to find a domain

  • The content of each square root must be \(\ge 0\).
  • Each denominator must not be 0.

A rational function has no square roots, so only the second rule applies. It is all about the denominator.

Find the domain of \(f(x) = \dfrac{2x - 9}{x^3 + 3x^2 + 2x}\).

Show solution
  1. Denominator\[x^3 + 3x^2 + 2x = 0\]
  2. Common factor\[x(x^2 + 3x + 2) = 0\]
  3. Factor again\(1\) and \(2\) multiply to \(2\) and add to \(3\): \[x(x + 1)(x + 2) = 0\]
  4. Split\[x = 0, \quad x = -1, \quad x = -2\]
  5. Excludeall three are outside the domain

Answerall x except 0, −1, and −2

Pull out the common factor first

A cubic looks intimidating, but every term here carries an \(x\), so factoring one out leaves a quadratic you can handle. Do that before anything else whenever the polynomial has no constant term.

Note also that the numerator plays no part. \(2x - 9\) is zero at \(x = 4.5\), and \(4.5\) is perfectly fine as an input; it just makes the output 0. Only denominators and square roots restrict a domain.
