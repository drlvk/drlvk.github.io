RecapTwo sign charts

Which sign chart to use
To find…We use…
Increasing/decreasing intervals, local maxima and minimaSign chart for the first derivative
Concave up/down intervals, inflection pointsSign chart for the second derivative

Both charts are built the same way. For \(f'\), mark where \(f' = 0\) or is undefined; a change \((+\ -)\) is a max and \((-\ +)\) is a min. For \(f''\), mark where \(f'' = 0\) or is undefined; each sign change is an inflection point, if \(f\) is defined there.

DefinitionWhat counts as an inflection point

Worth memorizing

  • A point of inflection is where \(f''\) changes sign and \(f\) is defined.

Does \(f(x) = x^4\) have an inflection point at \(x = 0\)? Note that \(f''(x) = 12x^2\), which is 0 at \(x = 0\).

Show solution
  1. Mark\(f''(x) = 12x^2 = 0\) only at \(x = 0\)
  2. Test\(f''(-1) = 12 > 0\);   \(f''(1) = 12 > 0\)
  3. Read off\(f''\) does not change its sign at 0, so it is not a point of inflection

Answerf is concave up on (−∞, 0) and (0, ∞); no points of inflection

Vertical asymptotes do not count

Derivatives can also change sign at a point with a vertical asymptote, but these do not count as points of inflection, maximum, or minimum. All these concepts require an actual point on the graph of \(f\).

ExampleA polynomial

The example below is similar to a homework 11.2 problem.

Let \(f(x) = -x^4 - 2x^3 + 36x^2 - 10x\). Find the intervals on which \(f\) is concave up or down. Then determine the \(x\)-coordinates of all inflection points of \(f\).

Show solution

We need a sign chart for \(f''\).

  1. f′\(f'(x) = -4x^3 - 2 \cdot 3x^2 + 36 \cdot 2x - 10 \cdot 1 = -4x^3 - 6x^2 + 72x - 10\)
  2. f″\(f''(x) = -4 \cdot 3x^2 - 6 \cdot 2x + 72 \cdot 1 - 0 = -12x^2 - 12x + 72\)
  3. Factorfactor out \(-12\): \(f''(x) = -12(x^2 + x - 6) = -12(x + 3)(x - 2)\)
  4. Mark\(f'' = 0\) at \(x = -3\) or \(x = 2\); \(f''\) is never undefined, since there is no denominator
  5. Test\(f''(-4) = (-12)(-1)(-6) < 0\);   \(f''(0) = (-12)(3)(-2) > 0\);   \(f''(3) = (-12)(6)(1) < 0\)

Answerconcave up on (−3, 2); concave down on (−∞, −3) and (2, ∞); points of inflection at x = −3 and x = 2

ExamplesExamples with “not defined” partition points

1. Let \(f(x) = x^2 - \dfrac{8}{x}\). Find the open intervals on which \(f\) is concave up or down. Then determine the \(x\)-coordinates of all inflection points of \(f\).

We need the second derivative. Remember that \(\dfrac8x = 8x^{-1}\), which makes the quotient rule unnecessary.

Show solution
  1. Rewrite\(f(x) = x^2 - 8x^{-1}\)
  2. f′\(f'(x) = 2x - 8(-1)x^{-2} = 2x + 8x^{-2}\)
  3. f″\(f''(x) = 2 + 8(-2)x^{-3} = 2 - \dfrac{16}{x^3}\)
  4. f″ = 0\(2 - \dfrac{16}{x^3} = 0\), so \(2 = \dfrac{16}{x^3}\), \(2x^3 = 16\), \(x^3 = 8\), so \(x = 2\) (since \(8^{1/3} = 2\))
  5. Undefined\(f''\) is undefined at \(x = 0\), and so is \(f\)
  6. Test\(f''(-1) = 2 - \dfrac{16}{(-1)^3} = 18 > 0\);   \(f''(1) = 2 - \dfrac{16}{1^3} = -14 < 0\);   \(f''(3) = 2 - \dfrac{16}{3^3} > 0\)

Answerconcave up on (−∞, 0) and (2, ∞); concave down on (0, 2); inflection at x = 2

The sign also changes at \(x = 0\), but \(f\) is not defined there, so 0 is not an inflection point.

2. One more such example. Let \(f(x) = \dfrac{3x - 2}{2x + 1}\). Find the open intervals on which \(f\) is concave up or down. Then determine the \(x\)-coordinates of all inflection points of \(f\).

Show solution
  1. f′quotient rule; do not expand the denominator: \[f'(x) = \frac{(3x-2)'(2x+1) - (3x-2)(2x+1)'}{(2x+1)^2} = \frac{3(2x+1) - (3x-2) \cdot 2}{(2x+1)^2} = \frac{6x + 3 - 6x + 4}{(2x+1)^2} = \frac{7}{(2x+1)^2}\]
  2. f″power chain rule on \(7(2x+1)^{-2}\), with inner function \(2x + 1\) and inner derivative 2: \[f''(x) = 7(-2)(2x+1)^{-3}(2) = -28(2x+1)^{-3} = \frac{-28}{(2x+1)^3}\]
  3. Markfor a fraction \(\frac{T}{B}\), \(T = 0\) makes it 0 and \(B = 0\) makes it undefined. Here \(-28 \ne 0\), and \((2x+1)^3 = 0\) when \(2x + 1 = 0\), \(x = -\frac12\).
  4. Test\(f''(-1) = \dfrac{-28}{(-2+1)^3} = \dfrac{-28}{-1} = 28 > 0\);   \(f''(0) = \dfrac{-28}{1^3} = -28 < 0\)

Answerconcave up on (−∞, −1/2); concave down on (−1/2, ∞); no inflection points

A sign change is not enough

In both examples the concavity changes at the point where \(f\) is undefined. That is a vertical asymptote, not a point on the graph, so it is never an inflection point.
