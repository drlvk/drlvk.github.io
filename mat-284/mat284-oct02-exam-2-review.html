Problem A · section 2.5Exponent rules

Simplify \(\dfrac{\left(x^6\right)^{3/2}}{x^2\sqrt{x}}\).

Show solution

The three laws in play

  • \(x^a \cdot x^b = x^{a+b}\)
  • \(\dfrac{x^a}{x^b} = x^{a-b}\)
  • \(\left(x^a\right)^b = x^{ab}\)
  1. Top\(6 \cdot \frac{3}{2} = \frac{6}{1}\cdot\frac{3}{2} = \frac{18}{2} = 9\), so \(\left(x^6\right)^{3/2} = x^9\)
  2. Bottom\(\sqrt{x} = x^{1/2}\), so \[x^2\sqrt{x} = x^2 x^{1/2} = x^{2 + 1/2} = x^{5/2}\]
  3. Divide\[\frac{x^9}{x^{5/2}} = x^{9 - 5/2} = x^{13/2}\]

Answerx¹³∕²

\(9 - \frac52 = \frac{18}{2} - \frac{5}{2} = \frac{13}{2}\). Writing every exponent as a fraction over 2 makes this subtraction routine.

Problem B · section 9.1A 0/0 limit

Find \(\displaystyle\lim_{x\to 2}\frac{x^2 + x - 6}{2x^2 - x^3}\).

Show solution
  1. Plug in 2top \(4 + 2 - 6 = 0\), bottom \(2\cdot 4 - 8 = 0\): the 0/0 form
  2. Factor top\[x^2 + x - 6 = (x-2)(x+3)\]
  3. Factor bottom\[2x^2 - x^3 = x^2(2 - x) = -x^2(x - 2)\]
  4. Cancel\[\lim_{x\to 2}\frac{(x-2)(x+3)}{-x^2(x-2)} = \lim_{x\to 2}\frac{x+3}{-x^2}\]
  5. Plug in 2\[\frac{2+3}{-4} = -\frac{5}{4}\]

Answer−5/4

Problem C · section 2.6A log equation

Solve \(\log_2(x + 1) + \log_2(x - 1) = 3\).

Show solution
  1. Combine\(\log_b(XY) = \log_b X + \log_b Y\), read backwards: \[\log_2\big((x+1)(x-1)\big) = 3\]
  2. Switch\(\log_b X = Y\) means \(X = b^Y\): \[(x+1)(x-1) = 2^3\]
  3. Simplify\[x^2 - 1 = 8 \quad\Longrightarrow\quad x^2 = 9\]
  4. Solve\(x = 3\) or \(x = -3\)
  5. Rejectat \(x = -3\) both inputs are negative, \(x + 1 = -2\) and \(x - 1 = -4\), and the logarithm of a negative number is undefined

Answerx = 3

Check: \(\log_2 4 + \log_2 2 = 2 + 1 = 3\). ✓

Always check the original equation

Combining the logs into one changed the domain. \(\log_2\big((x+1)(x-1)\big)\) is defined at \(x = -3\), since the product is \(8\), but the original two logarithms are not. Check every candidate in the original equation, not the simplified one.

Problem D · sections 2.5 and 2.6Continuous compounding

An investment of $1,000, compounded continuously, grew to $5,000 in 20 years. Find the annual rate.

Show solution

“Compounded continuously” means the model \(A = Pe^{rt}\), with \(r\) the rate and \(t\) the number of years. Here \(P = 1000\), \(t = 20\), and \(r\) is unknown.

  1. Equation\[1000\,e^{20r} = 5000\]
  2. Divide\[e^{20r} = 5\]
  3. Switchto log form, base \(e\): \[20r = \ln 5\]
  4. Solve\[r = \frac{\ln 5}{20} \approx 0.0805\]

Answerr = ln 5 / 20 ≈ 0.0805, that is 8.05%

Alternatively, apply \(\ln\) to both sides of \(e^{20r} = 5\): \(\ln\left(e^{20r}\right) = 20r\ln e = 20r\), since \(\ln e = 1\). Same answer either way.

Problem E · section 9.2A one-sided infinite limit

Find \(\displaystyle\lim_{x\to 1^-}\frac{2x - 5}{x^2 - 1}\).

Show solution
  1. Plug in 1\(\dfrac{2 - 5}{1 - 1} = \dfrac{-3}{0}\): the denominator vanishes and the numerator does not, so the answer is \(\infty\), \(-\infty\), or DNE
  2. Numerator\(\to -3\): negative
  3. Denominator\(x \to 1^-\) means \(x < 1\), so \(x^2 < 1\) and \(x^2 - 1 < 0\): negative. For instance \((0.9)^2 - 1 = -0.19\)
  4. Combine(negative) / (negative and close to 0) is large and positive

Answer∞

The side changes the answer

From the right, \(x^2 - 1\) is positive, so the quotient is (negative)/(positive) and heads to \(-\infty\). That is why the problem specifies \(x \to 1^-\). Without the minus sign the two-sided limit would not exist.

Problem F · section 2.6Expanding a logarithm

Write \(\log\left(\dfrac{x^5(x+2)^3}{\sqrt{x^2+4}}\right)\) in terms of \(\log x\), \(\log(x+2)\), and \(\log\left(x^2+4\right)\).

Show solution

The three laws

  • \(\log\frac{X}{Y} = \log X - \log Y\)
  • \(\log(XY) = \log X + \log Y\)
  • \(\log\left(X^r\right) = r\log X\)
  1. Quotient\[\log\big(x^5(x+2)^3\big) - \log\sqrt{x^2+4}\]
  2. Product\[= \log\left(x^5\right) + \log\left((x+2)^3\right) - \log\sqrt{x^2+4}\]
  3. Powers\(\sqrt{x^2+4} = (x^2+4)^{1/2}\): \[= 5\log x + 3\log(x+2) - \tfrac{1}{2}\log\left(x^2+4\right)\]

Answer5 log x + 3 log(x + 2) − ½ log(x² + 4)

\(\log(x^2+4)\) does not split any further: it is the logarithm of a sum, and there is no law for that.

Problem G · section 2.6An exponential equation

Solve \(4\cdot 7^{2-x} = 12\).

Show solution
  1. Divide by 4\[7^{2-x} = 3\]
  2. Apply ln\[\ln\left(7^{2-x}\right) = \ln 3\]
  3. Power law\[(2 - x)\ln 7 = \ln 3\]
  4. Divide\[2 - x = \frac{\ln 3}{\ln 7}\]
  5. Solve\[x = 2 - \frac{\ln 3}{\ln 7} \approx 1.435\]

Answerx = 2 − ln 3 / ln 7 ≈ 1.435

Subtracting 2 first gives \(-x = \frac{\ln 3}{\ln 7} - 2\), and flipping signs gives \(x = -\frac{\ln 3}{\ln 7} + 2\). That is the same answer written in a different order.

Divide before taking the logarithm

The 4 multiplies the exponential, so it comes off by division first. Taking \(\ln\) of \(4\cdot 7^{2-x}\) directly also works, using the product law, but it adds a \(\ln 4\) term you then have to carry around.

Problem H · section 9.2A limit at infinity

Find \(\displaystyle\lim_{x\to\infty}\frac{5x^2 - 4x^3}{5x^3 + 1}\).

Show solution
  1. Topthe highest power is \(-4x^3\), even though it is written second
  2. Bottomthe highest power is \(5x^3\)
  3. Keep those\[\lim_{x\to\infty}\frac{-4x^3}{5x^3} = -\frac{4}{5}\]

Answer−4/5

Same highest power on top and bottom, so the limit is the ratio of their coefficients. Grabbing the first term on top, \(5x^2\), instead of the highest power, would give 0.

Problem K · section 9.3Continuity of a piecewise function

Find all \(x\)-values at which the function below is discontinuous. Support your answer by computing the relevant limits and function values.

\[f(x) = \begin{cases} x + 3, & \text{if } x < -2 \\ 3 - x^2, & \text{if } -2 \le x \le 1 \\ 2x, & \text{if } x > 1\end{cases}\]
Show solution

Each piece is a polynomial, so continuous; only the transition points \(-2\) and \(1\) need checking. All three of the left limit, right limit and value must be equal for \(f\) to be continuous.

  1. At −2, left\[\lim_{x\to -2^-}(x+3) = -2 + 3 = 1\]
  2. At −2, right\[\lim_{x\to -2^+}\left(3 - x^2\right) = 3 - 4 = -1\]
  3. f(−2)\(-2\) is in the middle case: \(3 - (-2)^2 = -1\)
  4. At −2\(1 \ne -1\): not continuous
  5. At 1, left\[\lim_{x\to 1^-}\left(3 - x^2\right) = 3 - 1 = 2\]
  6. At 1, right\[\lim_{x\to 1^+}2x = 2\]
  7. f(1)\(1\) is in the middle case: \(3 - 1 = 2\)
  8. At 1all three equal 2: continuous

Answeronly x = −2

The question asks for supporting work

“Support your answer by computing the relevant limits and function values” means a bare “\(x = -2\)” is not enough. Show all three numbers at each transition point, including the one where nothing goes wrong. Showing that \(f\) is continuous at 1 is part of the answer.
