Problem A · section 10.4Chain rule practice

Three forms of the chain rule

  • \(\left(\square^a\right)' = a\,\square^{a-1} \cdot \square'\)
  • \(\left(b^{\square}\right)' = b^{\square} \ln(b) \cdot \square'\)
  • \(\left(\log_b \square\right)' = \dfrac{1}{\square \ln(b)} \cdot \square'\)

Each one ends with \(\square'\), the derivative of the inner function.

Find the derivatives of the following functions. (a) \(y = \left(8\sqrt{x} + 1\right)^6\)    (b) \(y = 5^{4x-3}\)    (c) \(y = \sqrt{x^2 + \ln(x)}\)

Show solution
  1. (a) inner\(8\sqrt{x} + 1\), with inner′ \(= 8 \cdot \frac12 x^{-1/2} = 4x^{-1/2}\)
  2. (a)\(y' = 6\left(8\sqrt{x} + 1\right)^5 \cdot 4x^{-1/2}\)
  3. (b)outer′ is \(5^{4x-3}\ln(5)\), inner′ is \((4x - 3)' = 4\): \(y' = 5^{4x-3} \cdot \ln(5) \cdot (4x - 3)' = 5^{4x-3} \cdot \ln(5) \cdot 4\)
  4. (c) rewrite\(y = \left(x^2 + \ln x\right)^{1/2}\), with inner function \(x^2 + \ln x\)
  5. (c)\[y' = \frac12\left(x^2 + \ln x\right)^{-1/2} \cdot \left(x^2 + \ln x\right)' = \frac12\left(x^2 + \ln x\right)^{-1/2} \cdot \left(2x + \frac1x\right)\]

Answer(a) 24x⁻¹∕²(8√x + 1)⁵   (b) 4 ln 5 · 5^(4x − 3)   (c) (2x + 1/x) / (2√(x² + ln x))

Problem B · section 10.7Elasticity of demand

Find the elasticity of demand at price level \(p = 15\), given the price-demand equation \((2x + 3)(p + 5) = 500\).

Show solution

Solve for \(x = f(p)\), then use \(E = -\dfrac{p\,f'(p)}{f(p)}\).

  1. Solve for x\(2x + 3 = \dfrac{500}{p + 5}\), so \(2x = \dfrac{500}{p + 5} - 3\) and \[x = \frac12 \cdot \frac{500}{p+5} - \frac12 \cdot 3 = \frac{250}{p + 5} - \frac32\] This is \(f(p)\).
  2. f′(p)quotient rule on the first term; the constant drops out: \[\left(\frac{250}{p+5} - \frac32\right)' = \frac{250' \cdot (p+5) - 250 \cdot (p+5)'}{(p+5)^2} = \frac{-250 \cdot 1}{(p+5)^2} = -\frac{250}{(p+5)^2}\]
  3. Put it in Emultiply the top and the bottom by \((p+5)^2\): \[E = \frac{-p \cdot \left(-\frac{250}{(p+5)^2}\right)}{\frac{250}{p+5} - 1.5} = \frac{250p}{250(p+5) - 1.5(p+5)^2}\]
  4. Plug in 15\[E = \frac{250 \cdot 15}{250 \cdot 20 - 1.5(20)^2} = \frac{3750}{4400} \approx 0.8523\]

AnswerE ≈ 0.8523 < 1, so demand is inelastic

Problem C · sections 10.4, 2.6Logarithms and the chain rule

More chain rule, but not just the chain rule: we also need the properties of logarithms.

Algebra rules

  • \(\ln\left(\dfrac{A}{B}\right) = \ln(A) - \ln(B)\)
  • \(\ln(AB) = \ln(A) + \ln(B)\)
  • \(\ln(A^r) = r\ln(A)\)

Find \(y'\) for \(y = \ln\left(\dfrac{\sqrt{3x^2 + 4}}{x^5}\right)\).

Show solution
  1. Algebra\(y = \ln\left(\sqrt{3x^2 + 4}\right) - \ln\left(x^5\right) = \dfrac12\ln(3x^2 + 4) - 5\ln(x)\)
  2. Calculusnext, the calculus rules: \[y' = \frac12 \cdot \frac{1}{3x^2 + 4} \cdot (3x^2 + 4)' - 5 \cdot \frac1x = \frac12 \cdot \frac{6x}{3x^2 + 4} - \frac5x\]

Answery′ = 3x/(3x² + 4) − 5/x

Problem D · section 11.1Increasing, decreasing, local extrema

For the function \(f(x) = \dfrac{x^2}{3 - x}\), determine where it is increasing or decreasing; also find the \(x\)-coordinates of the local maxima and minima.

Show solution

This needs a sign chart for \(f'\).

  1. Quotient rule\[f'(x) = \frac{(x^2)'(3 - x) - (x^2)(3 - x)'}{(3 - x)^2} = \frac{2x(3 - x) - x^2 \cdot (-1)}{(3 - x)^2} = \frac{6x - 2x^2 + x^2}{(3 - x)^2}\]
  2. Factor\(f'(x) = \dfrac{6x - x^2}{(3 - x)^2} = \dfrac{x(6 - x)}{(3 - x)^2}\)
  3. Partition\(f' = 0\) when \(x(6 - x) = 0\): \(x = 0\) or \(x = 6\). \(f'\) is undefined when \(x = 3\).
  4. Test\(f'(-1) = \frac{(-1)(6+1)}{(3+1)^2} < 0\);   \(f'(1) = \frac{(1)(6-1)}{(3-1)^2} > 0\);   \(f'(4) = \frac{4(6-4)}{(3-4)^2} > 0\);   \(f'(7) = \frac{7(6-7)}{(3-7)^2} < 0\)

Answerincreasing on (0, 3) and (3, 6); decreasing on (−∞, 0) and (6, ∞); local max at x = 6; local min at x = 0

Problem E · section 11.2Concavity and inflection

For the function \(f(x) = x\,e^{-2x}\), determine where it is concave up or down; also find the \(x\)-coordinates of the points of inflection.

Show solution

This needs a sign chart for \(f''\).

  1. f′a product, with inner function \(-2x\) in the exponential: \[f'(x) = (x)'e^{-2x} + x\left(e^{-2x}\right)' = 1 \cdot e^{-2x} + x \cdot e^{-2x} \cdot (-2) = (1 - 2x)e^{-2x}\]
  2. f″the product rule again: \[f''(x) = (1 - 2x)'e^{-2x} + (1 - 2x)\left(e^{-2x}\right)' = -2e^{-2x} + (1 - 2x)e^{-2x}(-2)\]
  3. Simplifyfactor out \(e^{-2x}\): \(f''(x) = \big(-2 + (1 - 2x)(-2)\big)e^{-2x} = (-2 - 2 + 4x)e^{-2x} = (-4 + 4x)e^{-2x}\)
  4. f″ = 0when \(-4 + 4x = 0\), that is \(4x = 4\), \(x = 1\); or \(e^{-2x} = 0\), which never happens, since \(e^{\square}\) is always \(> 0\)
  5. Test\(f''(0) = (-4)e^0 < 0\);   \(f''(2) = (-4 + 8)e^{-4} = 4e^{-4} > 0\)

Answerconcave up on (1, ∞); concave down on (−∞, 1); point of inflection at x = 1
