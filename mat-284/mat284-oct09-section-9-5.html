Warm-upTwo problems from WeBWorK

1. If the tangent line to \(y = f(x)\) at \((-1, -7)\) passes through the point \((6, -2)\), find \(f(-1)\) and \(f'(-1)\).

Show solution
  1. f(−1)the point \((-1, -7)\) is on the graph, with \(x = -1\) and \(y = -7\). So \(f(-1) = -7\).
  2. f′(−1)the slope of the tangent line at \(x = -1\), which we find from the two points on that line: \[\frac{-2 - (-7)}{6 - (-1)} = \frac{5}{7}\]

Answerf(−1) = −7  ·  f′(−1) = 5/7

2. Using the definition of derivative, find \(f'(x)\) for \(f(x) = \dfrac{3}{x+1}\).

Remember the four steps: substitute, subtract, simplify, let \(h \to 0\).

Show solution
  1. Substitutereplace \(x\) with \(x + h\): \[f(x+h) = \frac{3}{(x+h)+1} = \frac{3}{x+h+1}\]
  2. Subtractcombine over the common denominator: \[f(x+h) - f(x) = \frac{3}{x+h+1} - \frac{3}{x+1} = \frac{3(x+1) - 3(x+h+1)}{(x+h+1)(x+1)}\]
  3. Expand\[\frac{3x + 3 - 3x - 3h - 3}{(x+h+1)(x+1)} = \frac{-3h}{(x+h+1)(x+1)}\]
  4. Simplifydividing by \(h\) is the same as multiplying by \(\frac{1}{h}\): \[\frac{-3h}{(x+h+1)(x+1)} \cdot \frac{1}{h} = \frac{-3}{(x+h+1)(x+1)}\]
  5. Let h → 0\[f'(x) = \frac{-3}{(x+1)(x+1)} = \frac{-3}{(x+1)^2}\]

Answerf′(x) = −3/(x + 1)²

Keep the denominator factored

The subtraction is a difference of two fractions, so combine them over the common denominator \((x+h+1)(x+1)\) first. Then leave that denominator alone. The \(h\) you need to cancel is in the numerator, and multiplying out the denominator only makes it harder to see.

RecapWhat derivatives do, and how to write them

So far

Derivatives:

  • measure the rate of change of some quantity described by a function \(y = f(x)\);
  • can be computed by the definition as \(f'(x) = \lim\limits_{h\to 0}\dfrac{f(x+h)-f(x)}{h}\);
  • measure the slope of the tangent line to the graph of \(f\).

Instead of \(f'(x)\), there are other ways to write the derivative.

Notation for the derivative
NotationWhat it emphasizes
\(f'(x)\)the function \(f\) and its input
\(y'\)the output variable \(y\)
\(\dfrac{dy}{dx}\)the difference quotient idea: a difference of \(y\) over a difference of \(x\)
\(\dfrac{df}{dx}\)the same idea, but naming the function \(f\) instead of the output \(y\)

To differentiate something means to find its derivative. Differentiation is the process of finding a derivative.

Instead of using the definition each time we need a derivative, we can use the rules below. There will be more later.

Rule 1Constants

Worth memorizing

  • The derivative of a constant function is zero: \((c)' = 0\).

Take \(f(x) = 17\). Does \(f'(x) = 0\) make sense intuitively? How does it follow from the definition?

Show solution
  1. Intuition\(f'(x)\) is the rate of change of \(f(x)\). But \(f(x)\) never changes, so its rate of change is zero.
  2. Definitionwhatever goes in, 17 comes out, so \(f(x+h) = 17\) as well: \[\lim_{h\to 0}\frac{f(x+h)-f(x)}{h} = \lim_{h\to 0}\frac{17-17}{h} = \lim_{h\to 0}\frac{0}{h} = 0\]

Answer(17)′ = 0

Rule 2The power rule

The derivatives of \(x\) and \(x^2\) can be found using the definition of \(f'(x)\), and we essentially did this last time, while solving the example with \(f(x) = 2x - 3x^2\). These derivatives are \((x)' = 1\) and \((x^2)' = 2x\).

Similarly, we could use the definition to find the derivatives of \(x^3\), \(x^4\), and so on, but it takes more and more algebra: expanding \(\dfrac{(x+h)^3 - x^3}{h}\) already produces a bunch of terms. Instead, we record (and remember) one formula for the derivative of \(x^n\). It works for any power \(n\), which could be fractional or negative, or both.

Worth memorizing

  • \[(x^n)' = nx^{n-1}\]
  • Power rule: the old exponent is now a coefficient; the new exponent is 1 less.

The power rule can also handle some things that do not look like powers. Rewrite them as powers of \(x\) first.

Find the derivatives of the following functions.

(a) \(f(x) = x^5\)    (b) \(f(x) = \dfrac{1}{x}\)    (c) \(f(x) = \sqrt{x}\)    (d) \(f(x) = \dfrac{1}{x^2}\)    (e) \(f(x) = x^2\sqrt{x}\)

Show solution
  1. (a)\(f'(x) = 5x^4\)
  2. (b)rewrite as \(f(x) = x^{-1}\), then use the power rule: \[f'(x) = (-1)x^{-1-1} = (-1)x^{-2} = -\frac{1}{x^2}\]
  3. (c)rewrite as \(f(x) = x^{1/2}\), then \[f'(x) = \frac{1}{2}x^{\frac12 - 1} = \frac{1}{2}x^{-1/2} = \frac{1}{2x^{1/2}} = \frac{1}{2\sqrt{x}}\]
  4. (d)rewrite as \(f(x) = x^{-2}\), so the power rule applies: \[f'(x) = (-2)x^{-2-1} = -2x^{-3} = -\frac{2}{x^3}\]
  5. (e)rewrite as \(x^2 \cdot x^{1/2} = x^{2 + \frac12} = x^{5/2}\), then \[f'(x) = \frac{5}{2}x^{\frac52 - 1} = \frac{5}{2}x^{3/2}\]

Answer(a) 5x⁴   (b) −1/x²   (c) 1/(2√x)   (d) −2/x³   (e) (5/2)x³∕²

Rewrite first, then differentiate

Parts (b) through (e) all start by writing the function as \(x\) to a power, using \(\frac{1}{x^n} = x^{-n}\), \(\sqrt{x} = x^{1/2}\), and \(x^a \cdot x^b = x^{a+b}\).

Watch negative exponents: subtracting 1 makes them more negative. In (b), \(-1 - 1 = -2\), not 0.

Rule 3Constant multiples

Worth memorizing

  • The constant multiple rule: for any function \(f\) and any number \(k\), the derivative of \(kf\) is \(kf'\).

That is, we simply pull a constant factor out of the derivative.

Find \((3x^2)'\), \((3)'\), and \((3x)'\).

Show solution
  1. (3x²)′\(3x^2\) is \(3 \cdot x^2\), so we get \(3 \cdot (x^2)'\): \[(3x^2)' = 3(x^2)' = 3(2x) = 6x\]
  2. (3)′a stand-alone constant: \((3)' = 0\)
  3. (3x)′a constant attached by multiplication: \((3x)' = 3(x)' = 3 \cdot 1 = 3\)

Answer6x  ·  0  ·  3

When does a constant disappear?

How does the constant multiple rule square with the derivative of a constant being 0? It all depends on how the constant is involved. A stand-alone constant simply disappears in the derivative. A constant that is attached to a function by multiplication survives.

Find \(f'(x)\) for \(f(x) = \dfrac{5}{x}\).

Show solution
  1. Rewrite\(f(x) = 5x^{-1}\)
  2. Differentiateso \(f'(x) = 5(-1)x^{-2} = -\dfrac{5}{x^2}\)

Answerf′(x) = −5/x²

Don’t chain f and f′ with equal signs

It is tempting to write \(\frac{5}{x} = 5x^{-1} = 5(-1)x^{-2} = \frac{-5}{x^2}\) in one line. But the first two expressions are \(f(x)\) and the last two are \(f'(x)\), and those are not equal. Write \(f(x) = 5x^{-1}\), then start a new line: \(f'(x) = \dots\)

Division by a constant

What if a formula is divided by a constant? Division by a constant is multiplication by its reciprocal: for example, division by 3 is the same as multiplication by \(\frac13\). So when you are looking for the derivative of \(\dfrac{x^3}{7}\), think of it as \(\dfrac{1}{7}x^3\) and use the constant multiple rule.

Find \(\left(\dfrac{x^3}{7}\right)'\).

Show solution
  1. Constant out\[\left(\frac{x^3}{7}\right)' = \frac{1}{7}(x^3)' = \frac{1}{7} \cdot 3x^2 = \frac{3}{7}x^2\]

Answer(3/7)x²

Rule 4Sums and differences

Worth memorizing

The derivative can be distributed over \(+\) and \(-\) signs:

  • \((f + g)' = f' + g'\)
  • \((f - g)' = f' - g'\)

This does not work for products and quotients. We will get to those later.

With these rules we can handle any function that is a sum or difference of powers of \(x\), with any constant coefficients.

A. Find \(\left(5x^3 + 7x^2 - \dfrac{x}{3} + 24\right)'\).

Show solution
  1. Distributethe \(+\) and \(-\) signs between the terms are why the derivative distributes: \[(5x^3)' + (7x^2)' - \left(\frac{x}{3}\right)' + (24)'\]
  2. Each term\(5 \cdot 3x^2 = 15x^2\);   \(7 \cdot 2x = 14x\);   \(\frac{1}{3} \cdot 1 = \frac13\);   \((24)' = 0\)

Answer15x² + 14x − 1/3

B. Find \(\left(\dfrac{4x - x^5}{x^2}\right)'\).

Show solution

Be careful: the derivative does not distribute over quotients. The answer is not \(\dfrac{(4x - x^5)'}{(x^2)'}\).

  1. Rewritesplit the fraction: \[\frac{4x}{x^2} - \frac{x^5}{x^2} = 4x^{-1} - x^3\]
  2. Differentiate\[f'(x) = (4x^{-1})' - (x^3)' = 4(-1)x^{-2} - 3x^2 = -\frac{4}{x^2} - 3x^2\]

Answer−4/x² − 3x²

C. If \(f(x) = (6x^2 + 5x)\sqrt{x}\), what is \(f'(x)\)?

Show solution

Be careful: the derivative does not distribute over products. The answer is not \((6x^2 + 5x)'(\sqrt{x})'\).

  1. Rewritemultiply out, with \(\sqrt{x} = x^{1/2} = x^{0.5}\): \[f(x) = 6x^2 \cdot x^{0.5} + 5x \cdot x^{0.5} = 6x^{2.5} + 5x^{1.5}\]
  2. Differentiate\[f'(x) = 6 \cdot 2.5x^{1.5} + 5 \cdot 1.5x^{0.5} = 15x^{1.5} + 7.5x^{0.5}\]
  3. Tidy\(15x^{1.5} + 7.5x^{0.5} = 15x^{3/2} + 7.5\sqrt{x}\)

Answerf′(x) = 15x³∕² + 7.5√x

Products and quotients: rewrite first

For now, when you meet a product or a quotient, multiply it out or split the fraction until it is a sum of powers of \(x\). Then the four rules on this page are enough. Section 10.3 has rules for differentiating products and quotients directly.

ApplicationTangent lines

Some problems involving derivatives ask for the equation of a tangent line to the graph of some function \(y = f(x)\). Remember: you need the slope and a point.

Having the \(x\)-coordinate is enough information, because:

  • we can find the \(y\)-coordinate from the \(x\)-coordinate, using \(y = f(x)\);
  • the slope is the derivative \(f'(x)\) evaluated at the given point.

Find the tangent line to the graph \(y = 6x - x^3\) at the point with \(x = 2\).

Show solution
  1. Point\(y = 6(2) - 2^3 = 12 - 8 = 4\), so the point is \((2, 4)\)
  2. Derivative\(y' = (6x)' - (x^3)' = 6 - 3x^2\)
  3. Slopeat \(x = 2\): \(6 - 3(2)^2 = 6 - 12 = -6\)
  4. Linepoint-slope form with the point \((2, 4)\) and slope \(-6\): \(y - 4 = -6(x - 2)\)

Answery − 4 = −6(x − 2), or y = −6x + 16
