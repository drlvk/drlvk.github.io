Warm-upAn elasticity example from 10.7

Recall

If \(x = f(p)\), the demand equation solved for \(x\), then

  • \[E = -\frac{p\,f'(p)}{f(p)}, \quad\text{which is the same as}\quad E = -\frac{p}{x}\,\frac{dx}{dp}\]

The price-demand equation is \(9x^2 + 4p^2 = 160\). Find the elasticity of demand at price level \(p = 5\).

Show solution
  1. Solve for x\(9x^2 = 160 - 4p^2\), so \(x^2 = \dfrac{160 - 4p^2}{9}\) and \[x = \sqrt{\frac{160 - 4p^2}{9}} = \frac{\sqrt{160 - 4p^2}}{\sqrt 9} = \frac13\sqrt{160 - 4p^2}\] So \(f(p) = \frac13\sqrt{160 - 4p^2}\).
  2. f′(p)we need the chain rule (multiply by the inner derivative). The inner function is \(160 - 4p^2\), with derivative \(0 - 4(2p) = -8p\): \[\left[\tfrac13\left(160 - 4p^2\right)^{1/2}\right]' = \frac13 \cdot \frac12\left(160 - 4p^2\right)^{-1/2} \cdot (-8p) = -\frac86\,p\left(160 - 4p^2\right)^{-1/2}\]
  3. Edividing by \(\frac13\) is multiplying by 3, and \(-\frac12 - \frac12 = -1\): \[E = -\frac{p\left(-\frac86\right)p\left(160 - 4p^2\right)^{-1/2}}{\frac13\left(160 - 4p^2\right)^{1/2}} = \frac86 \cdot \frac31 \cdot p^2\left(160 - 4p^2\right)^{-1} = \frac{4p^2}{160 - 4p^2}\]
  4. Cancel 4correctly, as a factor of the whole denominator: \(\dfrac{4 \cdot p^2}{4 \cdot (40 - p^2)} = \dfrac{p^2}{40 - p^2}\)
  5. At p = 5\(E = \dfrac{25}{40 - 25} = \dfrac{25}{15} = \dfrac53 > 1\)

AnswerE = 5/3, so demand is elastic

Recall the three outcomes: \(E > 1\) elastic, \(E < 1\) inelastic, \(E = 1\) unit elasticity.

Exponent rule used

\(\dfrac{b^p}{b^r} = b^{p-r}\). Here \(\dfrac{(160 - 4p^2)^{-1/2}}{(160 - 4p^2)^{1/2}} = (160 - 4p^2)^{-1/2 - 1/2} = (160 - 4p^2)^{-1}\).

IdeaConcavity

The first derivative of a function \(f\) tells us if the graph of \(f\) is rising or falling. There are other ways to describe a graph, by how it is curved.

Definition

  • Concave up means the curve bends upward.
  • Concave down means the curve bends downward.

Concavity is related to the change of slope: concave up = the slope is increasing; concave down = the slope is decreasing.

Since the slope is the derivative \(f'(x)\), to determine the direction of concavity we need to find the rate of change of \(f'(x)\). That is, we need to find the derivative of the derivative: \((f')' = f''\).

DefinitionThe second derivative

The derivative of the derivative could be written as \(\left(f'(x)\right)'\), but there is better notation: \(f''(x)\). It is called the second derivative of \(f(x)\). If \(y = f(x)\), the second derivative can be written as \(y''\). Sometimes (rarely) the quotient notation is also used: \(y'' = \dfrac{d^2y}{dx^2}\). The forms \(y''\) and \(f''(x)\) are the most common.

Some examples of computing the second derivative. (a) Find the second derivative of \(f(x) = x^2 \ln x\).   (b) Given \(y = 2^{-5x}\), find \(y''\).

Show solution
  1. (a) f′ first\(f'(x) = (x^2 \ln x)' = (x^2)'\ln x + x^2(\ln x)' = 2x\ln x + x^2 \cdot \dfrac1x = 2x\ln x + x\)
  2. (a) f″\[f''(x) = (2x\ln x + x)' = (2x)'\ln x + 2x(\ln x)' + 1 = 2\ln x + 2x \cdot \frac1x + 1 = 2\ln x + 3\]
  3. (b) y′outer: \((2^x)' = 2^x \ln 2\); inner: \(-5x\), with derivative \(-5\): \(y' = 2^{-5x}(\ln 2)(-5)\)
  4. (b) y″\((\ln 2)(-5)\) is a constant factor, inherited from \(y'\): \[y'' = \left(2^{-5x}\right)' \cdot (\ln 2)(-5) = 2^{-5x}(\ln 2)(-5) \cdot (\ln 2)(-5) = 25(\ln 2)^2\, 2^{-5x}\]

Answer(a) f″(x) = 2 ln x + 3   (b) y″ = 25(ln 2)² · 2⁻⁵ˣ

The second derivative tells us how the rate of change of \(f(x)\) changes with time. For example, if \(f(t)\) is the position of an object at time \(t\), then \(f'(t)\) is its speed and \(f''(t)\) is its acceleration.

Worth memorizing

For us, a geometric interpretation is more important: the sign of \(f''(x)\) determines the concavity of the graph \(y = f(x)\). The graph is:

  • concave up where \(f''(x) > 0\);
  • concave down where \(f''(x) < 0\).

So we are going to need the sign chart of \(f''\).

DefinitionInflection points

Definition

Inflection points are those points on the graph of \(f\) where its concavity changes. This means two things:

  • \(f''\) changes its sign;
  • \(f(x)\) is defined at the place where the sign changes.

For example, the function \(f(x) = \dfrac1x\) does not have an inflection point at \(x = 0\). Its concavity changes there, but there is no inflection point, since \(f\) is not defined.

Note that having \(f'' = 0\) does not always indicate an inflection point: we also need \(f''\) to change its sign.

An example of \(f'' = 0\) without inflection

For \(f(x) = x^4\), \(f''(x) = 12x^2\), which is 0 at \(x = 0\). But \(12x^2\) is positive on both sides of 0, so the graph is concave up on both sides: no inflection point.

MethodSign chart for the second derivative

To construct the sign chart of \(f''(x)\)

  1. Find \(f''(x)\). Simplify and factor if possible.
  2. Mark the points where \(f'' = 0\) (or is undefined) on the number line. Construct a sign chart that shows, for each interval between the marked values, whether \(f''(x) > 0\) or \(f''(x) < 0\).

To determine the sign of \(f''\) for each interval, pick some number from it and plug it into \(f''\). The inflection points are those where the sign of \(f''\) changes and \(f\) is defined.

For the function \(f(x) = x^3 - 3x\), find its concavity and inflection points.

Show solution
  1. Need f″\(f'(x) = 3x^2 - 3\), so \(f''(x) = 3 \cdot 2x - 0 = 6x\)
  2. Markmark where \(f'' = 0\) or undefined: \(6x = 0\) when \(x = 0\)
  3. Test\(f''(-1) = 6(-1) < 0\);   \(f''(1) = 6 \cdot 1 = 6 > 0\)
  4. Inflectionthe sign changes at \(x = 0\), and \(f(0) = 0\) is defined: a point of inflection at \((0, 0)\)

Answerconcave up on (0, ∞); concave down on (−∞, 0); inflection at x = 0
