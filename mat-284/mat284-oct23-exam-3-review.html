ToolkitThe rules

The key to finding derivatives is the correct identification of the structure of a function.

Which rule to use
The function isIts derivative is
Sum or difference: \((\square) \pm (\square)\)\((\square)' \pm (\square)'\)
Something with a constant factor, like \(7 \cdot (\square)\)\(7 \cdot (\square)'\)
Just a constant, like \(7\)\(0\)
Power of the variable: \(x^n\)\(n x^{n-1}\)
Product: \((\square) \cdot (\blacksquare)\)\((\square)' \cdot (\blacksquare) + (\square) \cdot (\blacksquare)'\)
Quotient: \(\dfrac{(\square)}{(\blacksquare)}\)\(\dfrac{(\square)' \cdot (\blacksquare) - (\square) \cdot (\blacksquare)'}{(\blacksquare)^2}\)

Also need to remember

  • \((e^x)' = e^x\), which becomes \((b^x)' = b^x \ln b\) for other bases
  • \((\ln x)' = \dfrac{1}{x}\), which becomes \((\log_b x)' = \dfrac{1}{x \ln b}\) for other bases

Marginal cost, revenue, and profit: these are just derivatives of the totals.

Problem A · section 10.3Hidden details

One has to recognize the overall structure of a formula without getting lost in details. Some WeBWorK problems help by hiding the details.

Suppose that \(H(x) = f(x)/g(x)\), where \(g(4) = -9\), \(g'(4) = -2\), \(f(4) = 3\), \(f'(4) = -1\). Find \(H'(4)\).

Show solution
  1. Structurea quotient, top \(f\) and bottom \(g\): \[H'(x) = \frac{f'(x)g(x) - f(x)g'(x)}{g(x)^2}\]
  2. Put 4 for x\[H'(4) = \frac{f'(4)g(4) - f(4)g'(4)}{g(4)^2} = \frac{(-1)(-9) - (3)(-2)}{(-9)^2} = \frac{9 + 6}{81} = \frac{15}{81}\]

AnswerH′(4) = 15/81 = 5/27

Problem B · sections 9.5, 10.2, 10.3Choose your approach

Find the derivative of each of the following functions. Choose your approach carefully: some need algebra first, and some need the product or quotient rule.

(a) \(y = \dfrac{3x^5 - 6x}{5x}\)

Show solution
  1. Splita single term on the bottom, so the fraction splits: \[\frac{3x^5}{5x} - \frac{6x}{5x} = \frac35 x^4 - \frac65\]
  2. Differentiate\(y' = \dfrac35 \cdot 4x^3 - 0 = \dfrac{12}{5}x^3\), since \(\dfrac35 \cdot 4 = \dfrac35 \cdot \dfrac41 = \dfrac{12}{5}\)

Answery′ = (12/5)x³

(b) \(f(x) = \dfrac{\ln(x^3)}{3\sqrt{x}} + \dfrac{5}{x}\)

Show solution

Properties of logarithms

  • \(\ln(AB) = \ln A + \ln B\)
  • \(\ln(A/B) = \ln A - \ln B\)
  • \(\ln(A^r) = r\ln A\)
  1. Algebra\(\dfrac{5}{x} = 5x^{-1}\): no need for the quotient rule
  2. Algebra\(\dfrac{\ln(x^3)}{3\sqrt{x}} = \dfrac{\ln(x^3)}{3x^{1/2}} = \dfrac13 x^{-1/2}\ln(x^3)\): no quotient. And \(\ln(x^3) = 3\ln x\), so this is \(\dfrac13 x^{-1/2} \cdot 3\ln x = x^{-1/2}\ln x\).
  3. So far\(f(x) = x^{-1/2}\ln x + 5x^{-1}\)
  4. Calculusproduct rule on the first term: \[f'(x) = (x^{-1/2})'\ln x + x^{-1/2}(\ln x)' + 5(-1)x^{-2} = -\frac12 x^{-3/2}\ln x + x^{-1/2} \cdot \frac1x - \frac{5}{x^2}\]
  5. Tidysince \(x^{-1/2} \cdot \frac1x = x^{-3/2}\), this is also \(\dfrac{1 - \frac12 \ln x}{x^{3/2}} - \dfrac{5}{x^2}\)

Answerf′(x) = −(1/2)x⁻³∕² ln x + x⁻³∕² − 5/x²

(c) \(g(t) = (2^t + 1)(2t + 1)\)

Show solution
  1. Structurea product
  2. Product rule\(g'(t) = (2^t + 1)'(2t + 1) + (2^t + 1)(2t + 1)'\)
  3. Computewith \((2^t)' = 2^t \ln 2\), just as \((e^t)' = e^t\): \[g'(t) = (2^t \ln 2)(2t + 1) + (2^t + 1)(2)\]

Answerg′(t) = (2ᵗ ln 2)(2t + 1) + 2(2ᵗ + 1)

(d) \(y = \dfrac{4 - e^x}{2x^2 + 3}\)

Show solution
  1. Structurea sum on the bottom, so this one needs the quotient rule
  2. Quotient rule\[y' = \frac{(4 - e^x)'(2x^2 + 3) - (4 - e^x)(2x^2 + 3)'}{(2x^2 + 3)^2}\]
  3. Computewith \((2x^2)' = 2 \cdot 2x = 4x\): \[y' = \frac{(-e^x)(2x^2 + 3) - (4 - e^x)(4x)}{(2x^2 + 3)^2}\]

Answery′ = [−eˣ(2x² + 3) − 4x(4 − eˣ)] / (2x² + 3)²

Problem C · section 9.4The definition of derivative

Using the definition of derivative, find \(f'(x)\) for \(f(x) = \dfrac{3}{4 - x}\).

This is a four-step process: substitute, subtract, simplify and divide by \(h\), let \(h \to 0\).

Show solution
  1. Substitutereplace \(x\) with \(x + h\), in parentheses: \[f(x+h) = \frac{3}{4 - (x+h)} = \frac{3}{4 - x - h}\] Not \(\dfrac{3}{4-x} + h\), which adds \(h\), and not \(\dfrac{3}{4 - x + h}\), which loses the parentheses.
  2. Subtractover the common denominator, as in \(\dfrac{A}{B} - \dfrac{C}{D} = \dfrac{AD - BC}{BD}\): \[\frac{3}{4-x-h} - \frac{3}{4-x} = \frac{3(4-x) - 3(4-x-h)}{(4-x-h)(4-x)}\]
  3. Simplify\[= \frac{12 - 3x - 12 + 3x + 3h}{(4-x-h)(4-x)} = \frac{3h}{(4-x-h)(4-x)}\]
  4. Divide by hmultiply by \(\frac1h\) instead, if this helps, and cancel \(h\) correctly: \[\frac{3h}{(4-x-h)(4-x)} \cdot \frac{1}{h} = \frac{3}{(4-x-h)(4-x)}\]
  5. Let h → 0\[\lim_{h\to 0}\frac{3}{(4-x-h)(4-x)} = \frac{3}{(4-x)(4-x)} = \frac{3}{(4-x)^2}\]

Answerf′(x) = 3/(4 − x)²

Cancel only what multiplies

The \(h\) cancels because it is a factor of the whole numerator, \(3h\). In the denominator, \(4 - x - h\) has \(h\) as a term, not a factor, so it stays until the last step, when \(h \to 0\) turns it into \(4 - x\).

Problem D · section 9.7Marginal analysis: toasters

The total cost and the total revenue (in dollars) for the production and sale of \(x\) toasters are given, respectively, by \(C(x) = 8x + 2360\) and \(R(x) = 56x - 0.2x^2\).

(a) Find the marginal cost.   (b) Find the marginal revenue.   (c) Find the marginal profit.   (d) Find the value of \(x\) at which the marginal profit is 0.   (e) Find the average cost at the level of production from (d).

Show solution
  1. (a)(total cost)′ \(= (8x + 2360)' = 8\)
  2. (b)(total revenue)′ \(= (56x - 0.2x^2)' = 56 - 0.4x\)
  3. (c) profitunlike (a) and (b), we are not given the total profit function \(P(x)\), so we need to find it. Profit = revenue − cost: \[P(x) = (56x - 0.2x^2) - (8x + 2360) = 56x - 0.2x^2 - 8x - 2360 = 48x - 0.2x^2 - 2360\]
  4. (c) marginal\(P'(x) = (48x)' - (0.2x^2)' - (2360)' = 48 - 0.4x\)
  5. (d)solve \(P'(x) = 0\): \(48 - 0.4x = 0\), so \(x = \dfrac{48}{0.4} = 120\)
  6. (e)average cost = \(\dfrac{\text{total}}{x} = \dfrac{8x + 2360}{x} = 8 + \dfrac{2360}{x}\). Plug 120 for \(x\): \(8 + \dfrac{2360}{120} \approx 27.67\)

Answer(a) 8   (b) 56 − 0.4x   (c) 48 − 0.4x   (d) x = 120   (e) about $27.67 per toaster

Average is not marginal

At 120 toasters, the marginal cost is still $8: that is what one more toaster costs to make. The average cost is $27.67 because the fixed $2360 is spread over all 120 toasters. Part (e) needs no derivative at all.

Problem E · section 9.5A tangent line from f and f′

Suppose \(f(1) = -8\) and \(f'(1) = 6\). Find the equation of the tangent line to the graph of \(y = f(x)\) at \(x = 1\).

Show solution
  1. Read\(f(1) = -8\) gives the point: \(x = 1\), \(y = -8\). \(f'(1) = 6\) gives the slope at \(x = 1\).
  2. Linepoint-slope form, \(y - (\text{y value}) = (\text{slope})(x - (\text{x value}))\): \(y - (-8) = 6(x - 1)\)

Answery − (−8) = 6(x − 1), or y = 6x − 14

Two machines

Feed \(x\) into \(f\) and out comes the \(y\)-coordinate. Feed \(x\) into \(f'\) and out comes the slope.

Problem F · sections 9.5, 10.2, 10.3Three more derivatives

Find the derivative of (a) \(h(x) = \dfrac{x^2}{2^x + 10^x}\),   (b) \(g(x) = 4\log_5 x + 3\log_5 2\),   (c) \(f(x) = \dfrac{6x^3}{\sqrt{x}}\) (simplify first!).

Show solution
  1. (a) rulea quotient: \[h'(x) = \frac{(x^2)'(2^x + 10^x) - x^2(2^x + 10^x)'}{(2^x + 10^x)^2}\]
  2. (a) compute\[h'(x) = \frac{2x(2^x + 10^x) - x^2(2^x \ln 2 + 10^x \ln 10)}{(2^x + 10^x)^2}\]
  3. (b)\(3\log_5 2\) has no \(x\) in it, so its derivative is 0: \(g'(x) = 4 \cdot \dfrac{1}{x\ln 5} + 0 = \dfrac{4}{x \ln 5}\)
  4. (c) simplify\(f(x) = 6x^3 x^{-1/2} = 6x^{5/2}\)
  5. (c) power rule\(f'(x) = 6 \cdot \dfrac52 x^{3/2} = 15x^{3/2}\)

Answer(a) see above   (b) 4/(x ln 5)   (c) 15x³∕²

Constants in disguise

\(3\log_5 2\), \(\ln 7\), \(e^7\), and \(\sqrt{7}\) are all just numbers. Their derivative is 0, however complicated they look.
