DefinitionThe coordinate system

The rectangular coordinate system is two axes, one horizontal and one vertical. Usually the horizontal one is labeled \(x\) and the vertical one \(y\), but other letters appear. In this course the vertical axis will often be marked \(p\), for price.

Every point of the plane is a pair of numbers \((x, y)\), its coordinates. They say how far to move from the origin \((0,0)\): first in the horizontal direction, then in the vertical one. Negative coordinates mean moving the other way, left or down.

Two facts to keep

  • \(x = 0\) exactly when the point is on the \(y\)-axis
  • \(y = 0\) exactly when the point is on the \(x\)-axis

The order matters

\((5, 2)\) and \((2, 5)\) are different points. The first number is always the horizontal one.

MethodGraphs and intercepts

The coordinate system lets us graph any equation relating two variables, such as

\[x^2 + y^7 = \frac{50}{3x + 4y}\]

The graph is all the points whose coordinates satisfy the equation. For instance \((2, 1)\) satisfies this one, since \(2^2 + 1^7 = 5\) and \(\frac{50}{6 + 4} = 5\), so \((2,1)\) is part of the graph.

But that equation is far too complicated to work with. We focus instead on linear equations, which look like

\[Ax + By = C\]

for some constants \(A\), \(B\), \(C\). This is the standard form of a linear equation.

As the name suggests, the graph of a linear equation is a line. So we can draw it by finding just two points that satisfy the equation and connecting them. The easiest two to find are usually the intercepts.

Finding the intercepts

  • The \(y\)-intercept is where the graph crosses the \(y\)-axis. Plug in \(x = 0\) and solve for \(y\).
  • The \(x\)-intercept is where the graph crosses the \(x\)-axis. Plug in \(y = 0\) and solve for \(x\).

Graph \(12x + 5y = 30\) by finding its intercepts.

Show solution
  1. Set x = 0\[5y = 30 \quad\Longrightarrow\quad y = 6\]
  2. y-interceptthe point \((0, 6)\)
  3. Set y = 0\[12x = 30 \quad\Longrightarrow\quad x = 2.5\]
  4. x-interceptthe point \((2.5, 0)\)
  5. Drawplot both points and connect them

Answerthe line through (0, 6) and (2.5, 0)

When only one intercept exists

There are exceptional cases where only one variable is present, so only one intercept is available.

Graph \(3y = 6\) and \(2x = -5\).

Show solution
  1. First oneno \(x\) appears, so \(y = 2\) no matter what \(x\) is: a horizontal line through \((0,2)\)
  2. Second oneno \(y\) appears, so \(x = -2.5\) no matter what \(y\) is: a vertical line through \((-2.5, 0)\)

Answery = 2 is horizontal; x = −2.5 is vertical

Trying to find the missing intercept of \(y = 2\) means solving \(2 = 0\), which has no solution. That is the algebra telling you the line never crosses that axis.

DefinitionSlope

The slope of a line measures how steep it is. It can be computed from any two points on the line.

Worth memorizing

  • \[m = \frac{\text{difference of } y \text{ coordinates}}{\text{difference of } x \text{ coordinates}} = \frac{\text{vertical change}}{\text{horizontal change}}\]

This is the divided differences formula. Whichever point you call first, be consistent: the same order on top and on the bottom.

Find the slope of the line through \((3, 8)\) and \((5, 14)\).

Show solution
  1. Set up\[m = \frac{14 - 8}{5 - 3}\]
  2. Simplify\[m = \frac{6}{2} = 3\]

Answerm = 3

The \(14\) and the \(8\) are the vertical coordinates, and they go on top. Reversing both differences gives \(\frac{8-14}{3-5} = \frac{-6}{-2} = 3\), the same answer. Reversing only one gives \(-3\), which is wrong.

What the sign of the slope tells you

The four cases

  • Positive slope: as \(x\) increases, \(y\) increases. The line goes up.
  • Negative slope: as \(x\) increases, \(y\) decreases. The line goes down.
  • Zero slope: no vertical change, so the line is horizontal.
  • Vertical line: the slope is undefined, because the horizontal change is 0 and we cannot divide by 0.

A real data set

The population of Syracuse, in thousands of people, was 197 in 1970 and 149 in 2020. Find the slope of the line through these two data points.

Show solution

First decide what the variables mean: \(x\) is the year and \(y\) is the population in thousands. So the two points are \((1970, 197)\) and \((2020, 149)\).

  1. Set up\[m = \frac{149 - 197}{2020 - 1970}\]
  2. Simplify\[m = \frac{-48}{50} = -0.96\]

Answerm = −0.96

Read the units off the formula: thousands of people per year. The city lost about 960 people a year on average over those fifty years, and the slope is negative because the population fell.

ToolPoint-slope form

Knowing the slope of a line is not enough to find its equation. Why not? Because infinitely many different lines share the same slope; they are all parallel to each other. The slope fixes the direction but not the position.

But if you know the slope \(m\) and some point \((x_1, y_1)\) on the line, the equation follows.

Worth memorizing

  • \[y - y_1 = m(x - x_1) \qquad \text{(point-slope equation)}\]

Using the Syracuse data, write the equation of the line and use it to “predict” the population in 2050.

Show solution

We already found \(m = -0.96\). Take the point \((2020,\ 149)\).

  1. Substitute\[y - 149 = -0.96(x - 2020)\]
  2. Set x = 2050\[y - 149 = -0.96(2050 - 2020) = -0.96(30)\]
  3. Compute\[y - 149 = -28.8\]
  4. Solve\[y = 120.2\]

Answerabout 120.2 thousand people in 2050

Either point works

Using \((1970,\ 197)\) instead gives \(y - 197 = -0.96(x - 1970)\), which looks different but describes the same line. At \(x = 2050\) it also gives \(197 - 0.96(80) = 120.2\).

Why “predict” is in quotation marks

A line through two data points is the simplest possible model, not a forecast. It assumes the population keeps falling at exactly the same rate for another thirty years, which nothing guarantees. Extending a line past the data you have is extrapolation, and it is the part of the answer to be least confident about.

ToolSlope-intercept form

The point-slope equation \(y - y_1 = m(x - x_1)\) can be simplified to

\[y = mx + b \qquad \text{(slope-intercept equation)}\]

It is called that because the constant term \(b\) is the \(y\)-intercept of the line. This is really the same equation as before, written in a different form.

Put the Syracuse population equation into slope-intercept form.

Show solution
  1. Start\[y - 149 = -0.96(x - 2020)\]
  2. Distribute\[y - 149 = -0.96x + 1939.2\]
  3. Add 149\[y = -0.96x + 2088.2\]

Answery = −0.96x + 2088.2

Check both data points: at \(x = 1970\), \(-0.96(1970) + 2088.2 = 197\), and at \(x = 2020\), \(-0.96(2020) + 2088.2 = 149\). ✓

When b means nothing

Here \(b = 2088.2\) is the \(y\)-intercept, so it is the value the model gives at \(x = 0\), that is, in year 0. That is not a fact about Syracuse. \(b\) is a real feature of the line, but it only has a real-world meaning when \(x = 0\) is inside the range the model is about.

Poll question from class

Find the slope-intercept form of \(3x + 2y - 8 = 0\).

Show solution

Solve for \(y\). That is all “put it in slope-intercept form” ever means.

  1. Isolate 2y\[2y = -3x + 8\]
  2. Divide by 2\[y = -\frac{3}{2}x + 4\]
  3. Read offslope \(m = -1.5\), \(y\)-intercept \(b = 4\)

Answery = −1.5x + 4

Divide both terms on the right by 2. Halving the \(-3x\) but not the \(8\) is the usual slip.

Worked exampleParallel lines

Parallel lines have the same slope. That single fact turns a parallel-line question into a point-slope question.

Find the slope-intercept equation of the line that is parallel to \(3x + 2y = 7\) and passes through the point \((1, 10)\).

Show solution

The first job is to find the slope of the given line, since the line we want has the same one.

  1. Isolate 2y\[2y = 7 - 3x\]
  2. Divide by 2\[y = 3.5 - 1.5x, \quad\text{that is}\quad y = -1.5x + 3.5\]
  3. Slope\(m = -\frac{3}{2}\), or \(-1.5\); our line has the same slope
  4. Point-slopethrough \((1, 10)\): \[y - 10 = -\frac{3}{2}(x - 1)\]
  5. Distribute\[y - 10 = -\frac{3}{2}x + \frac{3}{2}\]
  6. Add 10\[y = -\frac{3}{2}x + \frac{23}{2}\]

Answery = −(3/2)x + 23/2

Check: at \(x = 1\), \(-\frac{3}{2} + \frac{23}{2} = \frac{20}{2} = 10\). ✓ And the slope is \(-\frac{3}{2}\), matching the given line. The two lines differ only in their intercepts, \(3.5\) against \(11.5\), which is exactly what being parallel means.

The order of operations

Find the slope of the given line first, then use the point. Doing it the other way round leaves nothing to substitute into the point-slope formula. And note that the constant \(7\) in \(3x + 2y = 7\) never enters the answer: it moves the given line up or down but does not change its direction.
