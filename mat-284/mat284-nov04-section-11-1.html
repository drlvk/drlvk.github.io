Warm-upAnother computation of elasticity

Recall

  • \[E = -\frac{p\,f'(p)}{f(p)} = -\frac{p\,x'}{x}, \qquad \text{where } x = f(p)\]

We need \(x\), the quantity, as a function of the price \(p\).

Given the price-demand equation \(p = 10/(x + 20)\), find the formula for the elasticity \(E\). Also evaluate the elasticity when \(p = 0.25\), and describe the demand as elastic, inelastic, or having unit elasticity.

Show solution

The equation is not solved for \(x\), so we need to solve for \(x\) first.

  1. Solve for xmultiply by the denominator: \(p(x + 20) = 10\). Divide by \(p\): \(x + 20 = \dfrac{10}{p}\). So \(x = \dfrac{10}{p} - 20\).
  2. dx/dp\(\dfrac{dx}{dp} = \left(\dfrac{10}{p} - 20\right)' = \left(10p^{-1} - 20\right)' = -\dfrac{10}{p^2}\)
  3. Formula\[E = -\frac{p}{x}\,\frac{dx}{dp} = \frac{-p}{\frac{10}{p} - 20} \cdot \left(-\frac{10}{p^2}\right) = \frac{10p}{10p - 20p^2}\] multiplying the top and the bottom by \(p^2\)
  4. Cancel p\(p\) is a factor of the whole denominator, so it cancels correctly: \[E = \frac{10p}{p(10 - 20p)} = \frac{10}{10 - 20p}\]
  5. At p = 0.25plug into \(E\): \(E = \dfrac{10}{10 - 20 \cdot 0.25} = \dfrac{10}{10 - 5} = 2 > 1\)

AnswerE = 10/(10 − 20p); at p = 0.25, E = 2, so demand is elastic

Separate the steps

You can write \(E = \dfrac{-p\left(10p^{-1} - 20\right)'}{10p^{-1} - 20}\) all at once, but it’s better to separate the steps: find \(x\), then \(dx/dp\), then put both into the formula. Each step is short and easy to check.

DefinitionsLocal extrema

In Chapter 11 the derivative \(f'\) is sometimes called the first derivative, to distinguish it from the second derivative \(f''\), which will appear later.

The goal of the chapter is to use derivatives to understand functions better. Some of the things we might want to know about a function are where it attains its maximal value, where it attains its minimal value, and where it increases or decreases. The motivation: maximization of profit, minimization of cost, and so on.

Functions can have complicated behavior, and to describe it, we need several terms.

Definition

  • \(f\) has a local maximum at \(a\) if \(f(a) \ge f(x)\) for all nearby points \(x\).
  • \(f\) has a local minimum at \(a\) if \(f(a) \le f(x)\) for all nearby points \(x\).

A local extremum is either a local maximum or a local minimum.

Latin plurals

  • maximum (singular), maxima (plural)
  • minimum (singular), minima (plural)
  • extremum (singular), extrema (plural)

If a local maximum is like a state champion, then an absolute maximum would be the world champion. We will deal with them later in this chapter.

MethodIncreasing and decreasing behavior

The derivative \(f'\), specifically its sign, will help us find the local extrema.

Worth memorizing

  • If \(f'(x) > 0\) on some interval (a positive rate of change), then the graph of \(f\) goes up: \(f\) is increasing on this interval.
  • If \(f'(x) < 0\) on some interval (a negative rate of change), then \(f\) is decreasing on this interval.

The function \(f\) cannot have any kind of local extremum within such intervals, because each point loses in comparison to a neighbor on one side and wins compared to the neighbor on the other side: neither max nor min.

How could a function stop being increasing (or decreasing)? In one of three ways:

  • a smooth turning point: \(f'\) becomes 0;
  • a sharp turning point: \(f'\) does not exist (a corner);
  • a gap in the graph: \(f\) itself does not exist.

Partition numbers and the sign chart

Therefore, we look for partition numbers for \(f'\): those where either \(f' = 0\), or \(f'\) is undefined, or \(f\) is undefined. (If \(f\) is undefined, \(f'\) is also undefined.)

Partition numbers divide the number line into intervals where \(f\) either increases or decreases. In each interval, we pick a test number to plug into \(f'\), because we need the sign of the derivative. This process produces a sign chart for \(f'\):

  1. Find \(f'(x)\). Simplify and factor if possible.
  2. Find the partition numbers and mark them on the number line.
  3. In each interval, choose some convenient test number and plug it into \(f'\) to find its sign.
  4. Mark each interval to show the sign of \(f'\) (\(+\) or \(-\)) and the behavior of \(f\) (increasing or decreasing).

For the function \(f(x) = 3x - x^3\), find the intervals where it is increasing and where it is decreasing.

Show solution
  1. 1. f′\(f'(x) = (3x - x^3)' = 3 - 3x^2 = 3(1 - x^2) = 3(1 - x)(1 + x)\)
  2. 2. Partition\(f'\) is always defined, and \(f' = 0\) when \(3(1 - x)(1 + x) = 0\): \(x = 1\) or \(x = -1\)
  3. 3. Testplug test numbers into \(3(1 - x^2)\): \(f'(-2) = 3(1 - 4) < 0\);   \(f'(0) = 3 > 0\);   \(f'(3) = 3(1 - 9) < 0\)
  4. 4. Chart\(-\) on \((-\infty, -1)\), \(+\) on \((-1, 1)\), \(-\) on \((1, \infty)\)

Answerincreasing on (−1, 1); decreasing on (−∞, −1) and (1, ∞)

TestFinding local extrema

Critical numbers

A local extremum can only occur where \(f'\) is 0 or undefined, and \(f\) itself is defined. Such numbers are called the critical numbers for \(f\).

A number for which \(f\) itself is undefined is a partition number but not a critical number. The function cannot have a local extremum there: a spike up to a vertical asymptote is neither a max nor a min.

Worth memorizing

The first-derivative test for local extrema says that for each critical number we should consider the signs of \(f'\) to the left and to the right of it.

  • The sign change \((+\ -)\) indicates a local maximum.
  • The sign change \((-\ +)\) indicates a local minimum.
  • No sign change \((+\ +\) or \(-\ -)\) indicates it’s not an extremum at all.

Use the sign chart we made for the first derivative of \(f(x) = 3x - x^3\) to find the local extrema of \(f\).

Show solution
  1. x = −1signs \((-\ +)\): local minimum
  2. x = 1signs \((+\ -)\): local maximum

Answerlocal min at x = −1; local max at x = 1

0 or undefined: only the signs matter

It does not particularly matter whether \(f'\) is 0 or undefined at the critical number: we only need its sign to the left and to the right of it. We do need \(f\) itself to be defined, otherwise there can be no extremum there.

PracticeOne more example

Find and classify the local extrema for the function \(f(x) = x + \dfrac{9}{x}\).

Show solution
  1. 1. f′\(f(x) = x + 9x^{-1}\), so \(f'(x) = 1 - \dfrac{9}{x^2}\)
  2. 2. Zero\(1 - \dfrac{9}{x^2} = 0\) gives \(x^2 = 9\), so \(x = 3\) or \(x = -3\)
  3. 2. Undefined\(f'\) is undefined at \(x = 0\), and so is \(f\)
  4. 3. Test\(f'(-4) = 1 - \frac{9}{16} = \frac{7}{16} > 0\);   \(f'(-1) = 1 - 9 = -8 < 0\);   \(f'(1) = -8 < 0\);   \(f'(4) = \frac{7}{16} > 0\)
  5. 4. Classify\(x = -3\): \((+\ -)\), local max.   \(x = 0\): \(f\) is not defined, so no extremum.   \(x = 3\): \((-\ +)\), local min.

Answerlocal max at x = −3 (value −6); local min at x = 3 (value 6)

A local max below a local min

The local maximum value, \(f(-3) = -3 - 3 = -6\), is smaller than the local minimum value, \(f(3) = 3 + 3 = 6\). Nothing is wrong: “local” means compared only with nearby points, and here the two are on opposite sides of the gap at \(x = 0\).
