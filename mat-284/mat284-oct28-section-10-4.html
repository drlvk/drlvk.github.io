IdeaComposing functions

To compose two functions means to use the output of one function as the input for another.

For example, given the functions \(f(x) = 3x - x^2\) and \(g(x) = 2x + \sqrt{x}\), we may decide to use the output of \(g\) as the input for \(f\). This creates a new function, read “f of g of x”:

\[f(g(x)) = 3\left(2x + \sqrt{x}\right) - \left(2x + \sqrt{x}\right)^2\]

We may say that \(f\) is the outer function here, and \(g\) is the inner function. (The textbook says “exterior” and “interior.”) Notice that every appearance of the variable in \(f\) is replaced by the formula for \(g(x)\).

Composition can also be done in the opposite order, plugging \(f\) into \(g\): fill each \(x\) in \(g(x) = 2x + \sqrt{x}\) with the inner function \(3x - x^2\).

\[g(f(x)) = 2\left(3x - x^2\right) + \sqrt{3x - x^2}\]

Now \(g\) is the outer function, and \(f\) is the inner function.

We will also need to recognize a given function as a composition of two simpler functions.

For each composition, what is the inner function, and what is the outer one?   \((5x+1)^3\),   \(5^{4x-3}\),   \(\sqrt{x^2 + 9}\),   \(\ln(x^3 + e^x)\)

The inner function is what you would compute first; the outer function is the last thing done to it.

RuleThe derivative of a composite function

How do we find the derivative of a function built by composition, such as \(y = \sqrt{x^2 + 4}\)? (No, this does not simplify to \(x + 2\).) Here the inner function is \(x^2 + 4\) and the outer one is the square root.

Think of the formula \(y = \sqrt{x^2 + 4}\) as a chain of production: the variable \(x\) is the raw material, from which an intermediate product \(x^2 + 4\) is made, and then the final product is made from the intermediate by taking the square root.

Let’s give a name to the intermediate product: \(u = x^2 + 4\). Then \(y = \sqrt{u}\) where \(u = x^2 + 4\). Find \(\dfrac{dy}{du}\), \(\dfrac{du}{dx}\), and then \(\dfrac{dy}{dx}\).

Show solution
  1. dy/du\(y = u^{1/2}\), so \(\dfrac{dy}{du} = \dfrac12 u^{-1/2} = \dfrac{1}{2\sqrt{u}}\)
  2. du/dx\(\dfrac{du}{dx} = 2x\)
  3. Chain rulemultiply them: \[\frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx} = \frac{1}{2\sqrt{u}} \cdot (2x) = \frac{1}{2\sqrt{x^2+4}} \cdot 2x = \frac{x}{\sqrt{x^2+4}}\]

Answerdy/dx = x/√(x² + 4)

Worth memorizing

The chain rule says that the derivative of the composite function is the product of the derivatives we just found:

  • \[\frac{dy}{dx} = \frac{dy}{du}\,\frac{du}{dx}\]
  • In words: (composition)′ = (outer)′ · (inner)′

“Derivative of \(y\) with respect to \(x\)” = “derivative of \(y\) with respect to \(u\)” times “derivative of \(u\) with respect to \(x\).” The fraction-like notation helps remember this: imagine canceling \(du\) on the right.

But it may be easier to remember the chain rule in words: the derivative of a composition is the product of two derivatives, of the outer function and of the inner function. Contrast this with the product rule, which does not actually have a product of two derivatives. The chain rule does.

The same computation can be written without naming \(u\). The outer function is \(y = \sqrt{u}\), and the inner function is \(u = x^2 + 4\):

\[\left(\sqrt{x^2+4}\right)' = \left((x^2+4)^{1/2}\right)' = \underbrace{\tfrac12 (x^2+4)^{-1/2}}_{\text{power rule}} \cdot \underbrace{(x^2+4)'}_{\text{chain rule}} = \frac12 (x^2+4)^{-1/2}(2x)\]

Multiply, don’t plug in

When finding the derivative of a composite like \(f(g(x))\), we do not plug one derivative into another, like \(f'(g'(x))\). That is not what the chain rule says. The chain rule involves multiplication: \(f'(g(x))\) is multiplied by \(g'(x)\).

\[\big(f(g(x))\big)' = f'(g(x)) \cdot g'(x)\]

PracticeIdentifying the intermediate expression

We can use the chain rule to find the derivative of any composition of two functions. The main step is to recognize that the formula we have is a composition.

1. A relatively simple example: find the derivative of \(y = (3x + 2)^5\).

Show solution
  1. Structureouter: raising to the 5th power; inner: \(3x + 2\)
  2. Chain rule(outer)′ times (inner)′: \[y' = 5(3x+2)^{5-1} \cdot (3x+2)' = 5(3x+2)^4 \cdot 3 = 15(3x+2)^4\]

Answery′ = 15(3x + 2)⁴

A very common mistake

Writing \(y' = 5(3x+2)^4\). That is only the derivative of the outer function. The correct solution uses the chain rule, which multiplies by the inner derivative, 3.

2. Find the derivative of the function \(y = \left(3 - \sqrt{x}\right)^8\).

Show solution
  1. Structureouter: the 8th power; inner: \(3 - \sqrt{x}\)
  2. Chain rule\[y' = 8\left(3 - \sqrt{x}\right)^7 \cdot \left(3 - \sqrt{x}\right)' = 8\left(3 - \sqrt{x}\right)^7\left(-\frac12 x^{-1/2}\right)\]
  3. Simplify\(8 \cdot \left(-\frac12\right) = -4\), and \(x^{-1/2} = \dfrac{1}{\sqrt{x}}\): \[y' = \frac{-4\left(3 - \sqrt{x}\right)^7}{\sqrt{x}}\]

Answery′ = −4(3 − √x)⁷/√x

3. A more complicated example: find \(f'(x)\) for \(f(x) = \dfrac{1}{\left(x^3 + \frac{2}{x}\right)^4}\). Try to avoid the quotient rule if possible. Recall \(\dfrac{1}{a^b} = a^{-b}\).

Show solution
  1. Rewrite\(f(x) = \left(x^3 + \dfrac{2}{x}\right)^{-4} = \left(x^3 + 2x^{-1}\right)^{-4}\). Outer: the \(-4\) power; inner: \(x^3 + 2x^{-1}\).
  2. Chain rule\[f'(x) = (-4)\left(x^3 + 2x^{-1}\right)^{-5} \cdot \left(x^3 + 2x^{-1}\right)'\]
  3. Inner\(\left(x^3 + 2x^{-1}\right)' = 3x^2 - 2x^{-2}\), so \[f'(x) = (-4)\left(x^3 + 2x^{-1}\right)^{-5}\left(3x^2 - 2x^{-2}\right)\]

Answerf′(x) = −4(x³ + 2x⁻¹)⁻⁵(3x² − 2x⁻²)

Copy the inner function unchanged

The outer derivative keeps the inner function exactly as it was: \(\left(x^3 + 2x^{-1}\right)^{-5}\), still with \(x^3\). Only the last factor, the inner derivative, has the \(3x^2\). And note that \(-4 - 1 = -5\): the exponent moves away from zero.

Special caseThe power chain rule

In the previous examples the outer function is just raising to a power. This happens often, so for convenience we isolate this case.

Worth memorizing

Power chain rule: when \(u\) is some expression and \(a\) is a number,

  • \[(u^a)' = a u^{a-1} u'\]
  • \(\big((\square)^a\big)' = a(\square)^{a-1} \cdot (\square)'\)

Find \(\left((x^3 - 2)^5\right)'\).

Show solution
  1. Power chainwith \(u = x^3 - 2\) and \(a = 5\): \(5(x^3 - 2)^4 \cdot (x^3 - 2)'\)
  2. Compute\(= 5(x^3 - 2)^4(3x^2) = 15x^2(x^3 - 2)^4\)

Answer15x²(x³ − 2)⁴

How is this different from the power rule that we started with, \((x^a)' = ax^{a-1}\)? There the inner function is just \(x\), whose derivative is 1, and we do not need to include the inner derivative when it’s just 1. If we have some expression (an inner function) raised to a power, the derivative of that inner function will appear at the end.

A few examples to try: find \(y'\) in each.   (a) \(y = \left(2x^3 - 8x\right)^{-12}\)    (b) \(y = \dfrac{1}{(3 + 5x)^3}\)

Show solution
  1. (a)\(u = 2x^3 - 8x\), \(a = -12\), and \(u' = 6x^2 - 8\): \[y' = -12\left(2x^3 - 8x\right)^{-13}\left(6x^2 - 8\right)\]
  2. (b) rewritewe don’t need the quotient rule here: \(y = (3 + 5x)^{-3}\)
  3. (b) chain\(u = 3 + 5x\), \(a = -3\), and \(u' = 5\): \[y' = -3(3 + 5x)^{-4} \cdot 5 = -15(3 + 5x)^{-4} = -\frac{15}{(3 + 5x)^4}\]

Answer(a) −12(2x³ − 8x)⁻¹³(6x² − 8)   (b) −15/(3 + 5x)⁴

Hidden detailsComposition with an unknown function

Suppose \(h\) is a function such that \(h(2) = 3\), \(h'(2) = -5\), \(h(8) = -2\), \(h'(8) = 7\).

(a) Let \(f(x) = h(x)^3\). Find the derivative \(f'(2)\).    (b) Let \(g(x) = h(x^3)\). Find the derivative \(g'(2)\).

Show solution
  1. (a) structure\(h(x)^3\) means \(\big(h(x)\big)^3\): outer is the cube, inner is \(h(x)\)
  2. (a) chain\(f'(x) = 3h(x)^2 \cdot h'(x)\), the last factor being (inner)′
  3. (a) at 2\(f'(2) = 3h(2)^2 \cdot h'(2) = 3 \cdot (3)^2 \cdot (-5) = -27 \cdot 5 = -135\)
  4. (b) structure\(h(x^3)\): outer is \(h\), inner is \(x^3\)
  5. (b) chain\(g'(x) = h'(x^3) \cdot (x^3)' = h'(x^3) \cdot 3x^2\)
  6. (b) at 2\(g'(2) = h'(2^3) \cdot 3 \cdot 2^2 = h'(8) \cdot 12 = 7 \cdot 12 = 84\)

Answer(a) f′(2) = −135   (b) g′(2) = 84

Order matters

\(h(x)^3\) and \(h(x^3)\) are different functions, in the same way that \((\ln x)^2 \ne \ln(x^2)\). Part (a) uses \(h(2)\) and \(h'(2)\); part (b) needs \(h'(8)\), because the inner function sends 2 to \(2^3 = 8\). The value \(h(8) = -2\) is not used at all.
