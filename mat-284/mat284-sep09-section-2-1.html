DefinitionWhat a function is

Abstractly, a function is any procedure that turns an input into an output.

Nothing in that definition says the input has to be a number. Two examples where it is not:

Counting the letters in a word

The input is a word, the output is a number, and the function is the process of counting letters.

“orange” \(\to 6\),   “calculus” \(\to 8\)

The day of the week

The input is a date, the output is a day of the week, and the function amounts to looking at a calendar.

09/16/2026 \(\to\) “Wednesday” (first exam),   12/11/2026 \(\to\) “Friday” (final exam)

NotationFunction notation

Once we consider several functions at once, the arrow notation becomes impractical. Each function needs a name, traditionally a symbol like \(f\), \(g\), \(h\).

Call the letter-counting function \(f\) and the calendar function \(g\). Then we can write

\[f(\text{“orange”}) = 6, \qquad g(09/16/2026) = \text{“Wednesday”}\]

The shape of the notation

  • (name of function)(input) \(=\) output
  • The input goes in parentheses, with the function's name in front of them.

The one mistake everybody makes

\(f(x)\) does not mean \(f\) times \(x\). The parentheses here are not multiplication, and none of the usual rules for multiplying apply. In particular, \(a(b+c) = ab + ac\) is true when \(a\) is a number and false when \(a\) is a function.

The same symbols can mean either thing, so you have to read the context: is that letter standing for a number, or for a function?

DefinitionDomain and range

The domain of a function is all the input values the function accepts. For the two examples above:

  • The domain of \(f\), the letter-counting function, consists of words.
  • The domain of \(g\), the day-of-the-week function, consists of dates.

So \(g(\text{“orange”})\) does not make sense: the input is not in the domain of \(g\). We say \(g(\text{“orange”})\) is undefined.

The range of a function is all the outputs it can produce.

  • The range of \(g\) is a set with seven elements: {“Monday”, “Tuesday”, “Wednesday”, “Thursday”, “Friday”, “Saturday”, “Sunday”}.
  • The range of \(f\) is some set of positive integers: a word cannot contain 0 letters, or a fractional number of them. Pinning it down exactly would mean deciding what counts as a word, that is, choosing a dictionary.

Which one to worry about

The range is generally harder to determine than the domain, and it matters less. The rest of this lecture is about the domain.

MethodFunctions given by formulas

In this course we deal with a particular kind of function: the input is a single number, and so is the output. Such functions are usually described by a formula.

For example, “add a 20% tip” can be written

\[y = x + \frac{20}{100}x = \left(1 + \frac{20}{100}\right)x = 1.2x\]

where \(x\) is the cost of dinner (the input) and \(y\) is the amount to be paid (the output). Factoring out the \(x\) gives the simpler formula \(y = 1.2x\).

Now compare that with this line. What is different?

\[T(x) = x + \frac{20}{100}x, \qquad \text{or} \qquad T(x) = 1.2x\]

This time we gave a name to the function itself; it is called \(T\). And we gave no name to the output, but it can always be referred to as \(T(x)\), meaning “the output you get if you plug \(x\) into \(T\).”

Using \(T(x) = x + \frac{20}{100}x\), evaluate:

a) \(T(70)\)    b) \(T(x-2)\)    c) \(T(z+h) + T(z-h)\)

Show solution

In each case, replace the variable in the formula for \(T\) by the given input. Whatever is handed to \(T\) goes everywhere \(x\) used to be.

  1. a) Substitute\[T(70) = 70 + \frac{20}{100}\cdot 70 = 70 + 14 = 84\]
  2. b) Substitute\[T(x-2) = (x-2) + \frac{20}{100}(x-2)\]
  3. b) Simplify\[= 1.2(x-2) = 1.2x - 2.4\]
  4. c) Substitute\[\Big[(z+h) + \tfrac{20}{100}(z+h)\Big] + \Big[(z-h) + \tfrac{20}{100}(z-h)\Big]\]
  5. c) Simplify\[= 1.2(z+h) + 1.2(z-h) = 1.2(2z) = 2.4z\]

Answer84,   1.2x − 2.4,   2.4z

The \(h\) cancels in part (c), which is worth noticing. Check with \(z = 5\) and \(h = 2\): \(T(7) + T(3) = 8.4 + 3.6 = 12\), and \(2.4(5) = 12\). ✓

Keep the parentheses

In part (b) the input is the whole quantity \(x-2\), so it needs its own parentheses: \((x-2) + \frac{20}{100}(x-2)\). Writing \(x - 2 + \frac{20}{100}x - 2\) applies the tip to only part of the bill and subtracts the 2 twice.

MethodFunctions vs equations

An equation with two letters in it is not automatically a function. Something more is required: each input must determine one output.

Does \(x^2 + y^2 = 25\) define \(y\) as a function of \(x\)? Why or why not?

Show solution

No. Take \(x = 3\).

  1. Substitute\[3^2 + y^2 = 25\]
  2. Simplify\[y^2 = 16\]
  3. Solve\[y = 4 \quad\text{or}\quad y = -4\]
  4. Conclusionthe input \(3\) does not determine a single output, so this is not a function

AnswerNo. One input gives two outputs.

On the other hand, some equations can be rearranged until the function is visible.

Rewrite \(\dfrac{8}{x^2} + \dfrac{5}{y} = 2\) so that it is clear \(y\) is a function of \(x\).

Show solution

Solve for \(y\).

  1. Isolate\[\frac{5}{y} = 2 - \frac{8}{x^2}\]
  2. Times y\[5 = \left(2 - \frac{8}{x^2}\right)y\]
  3. Divide\[y = \frac{5}{\,2 - \dfrac{8}{x^2}\,}\]

Answery = 5 / (2 − 8/x²)

Now each \(x\) produces exactly one \(y\), so this is a function. We will find its domain in the next section.

MethodFinding the domain

Not every number is an acceptable input. Sometimes the input jams the machine and nothing comes out. There are only two ways this happens in this course.

Worth memorizing

Find the domain by examining every square root and every denominator in the function.

  • The content of each square root must be \(\ge 0\).
  • Each denominator must not be 0, so exclude the inputs that make it 0.

Find the domain of \(y = \dfrac{5}{\,2 - \frac{8}{x^2}\,}\) from the previous section.

Show solution

There are two denominators here, not one, so there are two things to check.

  1. Inner\(x^2 = 0\) when \(x = 0\), so \(0\) is excluded
  2. Outer\[2 - \frac{8}{x^2} = 0 \quad\Longrightarrow\quad \frac{8}{x^2} = 2\]
  3. Solve\[x^2 = 4 \quad\Longrightarrow\quad x = 2 \ \text{ or } \ x = -2\]
  4. Excludeso \(0\), \(2\), and \(-2\) are all outside the domain

Answerall numbers except 0, 2, and −2

Two smaller examples, to isolate each rule.

Find the domain of a) \(f(x) = x + 1\),   b) \(f(x) = \dfrac{1}{x+1}\),   c) \(f(x) = \sqrt{x+4}\).

Show solution
  1. a)no roots and no denominators, so every number works: the domain is \((-\infty, \infty)\)
  2. b)the denominator \(x+1\) is 0 when \(x = -1\): all numbers except \(-1\)
  3. c)we cannot take square roots of negatives, so we need \(x + 4 \ge 0\), that is \(x \ge -4\), or \([-4, \infty)\)

Answer(−∞, ∞);   all except −1;   [−4, ∞)

Two rules, two shapes of answer

A denominator removes isolated points from the number line, so the answer reads “all numbers except …”. A square root cuts off a whole ray, so the answer is an inequality or an interval. When a function has both, you get both kinds of restriction at once, as in the last example below.

Worked exampleWorked domains

Poll question from class

Find the domain of \(f(x) = \dfrac{4 + 3x}{\sqrt{x - 2}}\).

Show solution

The square root is in the denominator, so both rules apply to the same expression.

  1. Root\(\sqrt{x-2}\) requires \(x - 2 \ge 0\), so \(x \ge 2\)
  2. Denominator\(\sqrt{x-2} = 0\) when \(x = 2\), so \(2\) must be excluded
  3. Combinewe need \(x \ge 2\) but not \(x = 2\), so \(x > 2\)

Answerx > 2, that is (2, ∞)

The two rules pull in the same direction here, and the endpoint is the casualty. Answering \(x \ge 2\) misses the second rule.

Find the domain of \(g(x) = \dfrac{4 + 3x}{\sqrt{x} - 2}\).

Show solution

Notice how little changed in the formula, and how much changed in the answer. The \(-2\) is now outside the root.

  1. Root\(\sqrt{x}\) requires \(x \ge 0\)
  2. Denominator\(\sqrt{x} - 2 = 0\) when \(\sqrt{x} = 2\), that is \(x = 4\)
  3. Combine\(x \ge 0\), excluding \(4\)

Answerall x ≥ 0 except 4, that is [0, 4) ∪ (4, ∞)

\(\sqrt{x-2}\) against \(\sqrt{x}-2\)

These two problems have the same numerator and nearly the same denominator, and their domains are \((2,\infty)\) and \([0,4)\cup(4,\infty)\). Read carefully where the root ends. Everything inside it faces the \(\ge 0\) rule; everything outside it does not.

Find the domain of \(h(t) = \dfrac{\sqrt{2t + 5}}{9 - t^2}\).

Show solution
  1. Root\(2t + 5 \ge 0\), so \(t \ge -\frac{5}{2} = -2.5\)
  2. Denominator\[9 - t^2 = 0 \quad\Longrightarrow\quad t^2 = 9 \quad\Longrightarrow\quad t = 3 \ \text{ or } \ t = -3\]
  3. Check both\(-3\) is already below \(-2.5\), so it was never allowed; only \(3\) has to be removed
  4. Combine\(t \ge -2.5\), excluding \(3\)

Answer[−2.5, 3) ∪ (3, ∞)

Check each excluded point against the other rule

The denominator produced two candidates, \(3\) and \(-3\), but \(-3\) sits outside the region the square root already permits. Writing the answer as “\(t \ge -2.5\) except \(3\) and \(-3\)” is not wrong so much as redundant, and on an interval-notation question it costs you the point. Draw the number line and the overlap becomes obvious.
